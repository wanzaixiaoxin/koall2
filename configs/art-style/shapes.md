# shapes.md — 形状语言规范（docs/06 §2）

> 三条纪律：① 友方=圆与圆角，敌方=三角与尖角，城墙/场景=矩形与网格；
> ② 全游戏色板 ≤ 12 色（见 palette.json），同屏主色 ≤ 3；
> ③ 生命力来自动效（见 fx-config.json），不来自贴图。

## 形状语言总表

| 阵营/元素 | 基础形状 | 描边 | 动效身份 |
|-----------|----------|------|----------|
| 主英雄 | 正三角机身 + 圆形核心 + 双圆角翼 | 2px 高亮描边 | 移动前倾；射击后坐 2px 回弹；待机呼吸 ±3px |
| 辅助单位 | 职业图腾：法师=菱形 / 射手=五边形 / 坦克=圆角方块 | 1.5px | 环绕英雄带相位差浮动；施法核心亮度脉冲 |
| 城墙 | 底部圆角矩形城垛序列（分段） | 无 | 受击段抖动；100/70/40/20% 四档缺角；<30% 红光呼吸 |
| 精英 | 同族形状 ×1.6 + 双层描边脉冲 + 词缀色光环 | 3px 双层 | 词缀触发光环爆闪 |
| Boss | 多层几何嵌套（如树人=三角层叠 + 旋转外环） | 3px | 阶段切换全屏震动 + 色温转冷 + 外环碎裂重组 |

## 可读性铁律

1. 层级亮度：玩家 > 弹幕 > 精英/Boss > 小怪 > 场景；
2. 受击闪白全覆盖（含城墙分段）——最高优先级动效；
3. 投射物统一高亮描边，拖尾统一 80ms 渐隐；
4. 预警（dash 线、落石圈）是程序化 UI 层，不依赖美术资产；
5. 每个元素至少有一个专属动效（入场/待机/受击/死亡之一）。

## 2D 渲染分层（Web 适配层实现补充）

> 本节是「几何 ≠ 简陋」在 2D 程序绘制里的具体落地：不引入位图，仅靠 **分层 + 受光 + 描边 + 动效** 把几何体做出设计感。
> 实现：`src/adapter/web/render/`（style 基础层 / shapes 形体 / particles 特效 / scene 场景编排）。

### 1. 单位绘制的五层结构（每个怪物都遵守）

| 层 | 内容 | 目的 |
|----|------|------|
| ① 接地阴影 | 脚下软圆盘（压扁、按体型缩放，飞行单位更小更淡） | 让单位"站在地面"而不是"贴在屏幕" |
| ② 墨线 | 深夜色 `#0B0C1D` 外描边 2~2.8px | 从夜空里"抠"出轮廓（受击闪白也沿此轮廓） |
| ③ 底色块 | 本体主色（同族色系） | 识别阵营/种类 |
| ④ 受光面 | 内缩同形状、偏上、按主色提亮 34% | 体积感（左上光源的统一约定） |
| ⑤ 高光/暗部 | 顶部反光弧、左上镜面高光、底部压深 | 材质区分（软体/甲壳/金属） |

派生色一律由色板既有色"加白/压深"得到，**不新增色相**。

### 2. 每个单位的专属动效与信息型表现

| 单位 | 待机/移动 | 信息型表现（好看且不误导） |
|------|-----------|------------------------------|
| 英雄 | 悬浮呼吸 ±3px、机身随移动前倾、喷焰闪烁、炮塔追踪最近敌人 | 开火后坐 + 炮口闪光；核心脉动是最亮点（玩家优先级最高） |
| 史莱姆 | 弹跳 squash、体内气泡上浮 | 移动起伏（快慢可读） |
| 野狼 | 冲刺拉伸、尾巴甩动 | 前摇：脚下蓄力圈 + 眼睛转红 |
| 冲锋鼠 | 速度线 + 残影 + 尖端高光 | 残影只在行进中出现（驻留时无，避免误导） |
| 投矛手 | 长矛随攻击后仰→投出 | 攻击前摇时眼睛变红 |
| 投石车（重型投矛手） | 轮式平台滚动、抛臂蓄力 | 抛臂后仰角度 = 蓄力进度 |
| 岩甲兽 | 腿部交替迈步、甲片分层 | 护盾弧亮起 = 免伤层数；头顶刻度 = 剩余层数 |
| 夜行蝙蝠 | 双翼扑动、缺口翼缘 | 飞行残影 |
| 分裂菇 | 伞盖摇摆、孢子飘散 | 摇摆幅度随移动 |
| 地精巫师 | 法袍浮动、法球呼吸、符文环绕 | 符文环 = 施法者身份 |
| 虫后 | 膜翼扇动、卵囊脉动 | 治疗环扩张进度 = 下次治疗倒计时 |
| 毒爆虫 | 囊体脉动、膜瓣常驻脉络 | 脉动频率/裂纹亮度 = 危险度；临爆高频闪白 |
| 幼虫/爬虫/潜伏者/雷兽 | 体节蠕动 / 六足步进 / 刃尖起落 / 甲壳呼吸 | 钻地：土包 + 虚线"看得见打不到"；潜伏者攻击时刃口发光 |
| 腐化树人（Boss） | 树冠摇摆、双层外环反向旋转 | 核心竖瞳注视感 + 脚下威压光环 |

### 3. 全局表现层

- **背景**：预渲染夜空渐变 + 网格 + 星尘 + 暗角（离屏缓存，逐帧只 blit），再叠缓慢漂移的微尘。
- **城墙**：12 段独立城垛砖墙，四档破损（100/70/40/20%）按段确定性差异；受击段抖动 + 白闪 + 碎屑；<30% 红光呼吸 + 全屏告急暗角。
- **特效**：击杀碎裂（碎片形状跟随本体色）、爆炸（火球闪 + 冲击环 + 余烬 + 烟 + 震屏）、命中火花、连锁电弧（锯齿 3 层光带）、治疗环、伤害转嫁电弧、升级金环、炮口闪光。
- **飘字**：描边 + 弹出缩放；暴击更大更金。
- **性能**：光晕/阴影走预渲染精灵，粒子硬上限 320，投影/渐变不逐单位创建（同屏 150 怪仍 60fps）。
