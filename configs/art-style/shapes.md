# shapes.md — 形状语言规范（docs/06 §2）

> 三条纪律：① 友方=圆与圆角，敌方=三角与尖角，城墙/场景=矩形与网格；
> ② 全游戏色板 ≤ 12 色（见 palette.json），同屏主色 ≤ 3；
> ③ 生命力来自动效（见 fx-config.json），不来自贴图。

## 形状语言总表

| 阵营/元素 | 基础形状 | 描边 | 动效身份 |
|-----------|----------|------|----------|
| 主英雄 | 正三角机身 + 圆形核心 + 双圆角翼 | 2px 高亮描边 | 移动前倾；射击后坐 2px 回弹；待机呼吸 ±3px |
| 辅助单位 | 职业图腾：法师=菱形 / 射手=五边形 / 坦克=圆角方块 | 1.5px | 环绕英雄带相位差浮动；施法核心亮度脉冲 |
| 城墙 | 底部圆角矩形城垛序列（分段） | 无 | 受击段抖动；100/70/40/20% 四档缺角；<30% 红光呼吸 |
| 精英 | 同族形状 ×1.6 + 双层描边脉冲 + 词缀色光环 | 3px 双层 | 词缀触发光环爆闪 |
| Boss | 多层几何嵌套（如树人=三角层叠 + 旋转外环） | 3px | 阶段切换全屏震动 + 色温转冷 + 外环碎裂重组 |

## 可读性铁律

1. 层级亮度：玩家 > 弹幕 > 精英/Boss > 小怪 > 场景；
2. 受击闪白全覆盖（含城墙分段）——最高优先级动效；
3. 投射物统一高亮描边，拖尾统一 80ms 渐隐；
4. 预警（dash 线、落石圈）是程序化 UI 层，不依赖美术资产；
5. 每个元素至少有一个专属动效（入场/待机/受击/死亡之一）——**怪物看轮廓与死法，
   武器看子弹与炮口，两两不共用**（逐怪/逐武器身份见 identity.ts）。
