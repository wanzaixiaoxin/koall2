# P5 评审与迭代记录（docs3d/log-p5.md）

> 双角色循环：制作人（规划/验收）→ 玩家（体验/提意见）→ 制作人（修）→ 复验
> 每轮一个 tag：p5-round1 / p5-round2 / p5-round3

## 第 1 轮（tag backup/p5-round1）

**玩家评审问题清单**（按严重度）：
1. 【高】怪物在深色地面+雾中辨识度低
2. 【高】命中反馈弱：闪白几乎不可见、火花太小——打击感不足
3. 【高】英雄朝向固定，火力来源不直观
4. 【高】完全静音
5. 【中】经验宝石太小
6. 【中】没有开始画面，进入即战斗
7. 【中】波间休整太空

**迭代**：
- WebAudio 合成音效 `sfx.ts`（射击/命中/爆炸/墙击/升级/宝石/波次号角，M 键静音，零素材）
- 开始画面 `start-screen.ts`（操作引导 + 解锁 AudioContext 手势）
- 怪物自发光增强 + 呼吸脉动（每实例相位错开）
- 英雄火力朝向：每帧转向最近敌人（渲染层计算，不进内核）
- 宝石 0.13→0.22；波间倒计时横幅（"✔ 波次肃清 · 下一波 4s"）

**复验**：开始画面 ✅ / 音效（代码审查，自动化无声卡）✅ / 英雄转向可见 ✅

## 第 2 轮（tag backup/p5-round2）

**玩家评审**：英雄推到防守区最前沿时下半身被城垛遮挡（2D 俯视不存在、3D 视角结构性问题）；怪物自发光仍不够。

**迭代（治本）**：
- 墙体从 z=1.25 外移至 z=2.4、高度 3.2→2.6——墙在英雄与镜头之外，任何走位都不遮挡
- 镜头默认俯角加深（back 7.6→6.8 / height 6.4→8.0，威胁收紧时更高）
- 怪物 emissive ×0.85→×1.3

**复验**：英雄最前沿完整可见 ✅（截图确认）

## 第 3 轮（tag backup/p5-round3）

**玩家评审**：怪物无血条（2D 版有，信息缺失）；拖尾太短速度感弱；屏幕边缘红光误触发（单怪偏侧就全亮，过强）。

**迭代**：
- `hp-bars-render.ts`：billboard 点精灵血条（单 draw call，只在 hp<maxHp 显示，绿/黄/红变色），
  首版尺寸失控（gl_PointSize 46×150/z 巨大矩形糊屏）→ 二次修正 16×60/z
- 拖尾长度 ×4（速度线感）
- 边缘红光系数 0.35→0.12、上限 0.9→0.5

**复验**：画面干净、红光克制、血条待受伤后观察（设计如此）
