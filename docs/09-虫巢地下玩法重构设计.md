# 09 第二章「虫巢地下」玩法重构设计（侵蚀网 · 出生线推进 · 地堡反制）

> 状态：设计稿（未实现）｜ 作者：与玩家共同设计 ｜ 依赖：docs/08（虫族单位）、docs/06（美术规范）
> 一句话：**这不是"打一波怪"，而是"和一张会生长的地下网络抢地盘"。**
> 虫海是表象，真正的敌人是**地下侵蚀网**——它无声扩张、把出生点拽到你脸上、给虫群供血供能；
> 你唯一有效的反制是在自己的活动区里**造地堡/工事**，把土地"钉死"。

---

## 1. 设计目标（玩家体验曲线）

| 阶段 | 玩家感受 | 系统表现 |
|------|----------|----------|
| 开局（0–2 波） | "虫子好弱，随便打" | 虫血薄、数量多，普通攻击够用 |
| 中局（3–6 波） | "不对劲，它们出生点越来越近" | 侵蚀网蔓延，出生线前移，压力骤增 |
| 转折（7–8 波） | "得管地下那张网，不然守不住" | 地堡解锁，玩家开始"抢地盘" |
| 高潮（9–10 波） | "守住最后一块地" | 侵蚀逼近城墙，地堡覆盖区成为唯一安全落点 |

**核心张力**：不是"火力够不够"，而是**"你愿意花多少资源去抢土地"**——塔/武器 vs 地堡，形成真实取舍。

---

## 2. 核心系统：地下侵蚀网（Burrow Web）

### 2.1 形态：节点 + 连线的网状结构

- **节点（Node）**：埋在地下的"虫巢结点"，直径约 60px，**不可被普通子弹瞄准**（不进入索敌表）。
- **连线（Link）**：节点之间在地下相连，构成网状；连线是"供能/供血通道"。
- **整张网**是一张**会生长的图**：节点从场地深处的"虫巢核心"开始，逐波向外长出新节点。

### 2.2 关键规则

| 规则 | 说明 |
|------|------|
| **不可瞄准** | 节点/连线不在武器的索敌范围内，子弹打不到（"一般子弹无法瞄准它"） |
| **本身无攻击性** | 不攻击城墙/英雄，纯"地形/资源"实体 |
| **生命极强** | 不是靠"打掉血条"消灭，而是靠**地堡压制**（见 §4），血量只是缓慢消耗的辅助 |
| **缓慢蔓延** | 每 N 秒长出 1 个新节点（N 随波次缩短），节点优先朝**城墙方向**、其次朝**未覆盖空地**扩张 |
| **供血供能** | 节点覆盖区（以节点为中心的"侵蚀地格"）内的虫族：**HP 上限 +攻击力提升**（随网的规模/距离核心的远近分档）；等效替代现有"虫苔回血" |
| **出生线前移** | **虫子的出生点 = 当前最靠近城墙的侵蚀节点**（而不是固定出生带）。网越往前，怪就从越靠前的地方钻出来 |
| **地堡免疫** | 地堡覆盖的地块**永久不可被侵蚀**，网无法长入、已有侵蚀会被"顶掉" |

### 2.3 与现有"虫苔 creep"的关系

- 现有 `creep`（90px 网格虫苔，加速+回血、火焰可烧）**降级为"侵蚀网的视觉表现层"**：
  - 节点/连线的渲染 → 复用/扩展 `creep` 地块的绘制（有机团块、脉纹、边缘亮弧）。
  - "虫苔回血" → 升级为**节点供血（HP 上限/攻击力提升）**。
- **火焰烧虫苔**保留：火焰可以**烧断连线**（暂时切断供能），但**不能摧毁节点**（节点只能被地堡压掉）——这让火系从"清苔"升级为"战术断线"。

## 3. 出生线推进（Spawn Front）

```
初始：spawnFrontY = 1600（底部出生带）
每次侵蚀网长出"更靠前"的节点 → spawnFrontY = min(spawnFrontY, nodeY - 余量)
```

- 出生点从"固定 `spawnBandY [1600,1880]`"改为**沿侵蚀网前沿**：
  - 有新节点比当前前沿更靠前 → 怪从那个节点附近钻出（有"出土"动画）。
  - 若该前沿节点被地堡顶掉/烧断 → 出生线回退到下一个可用的前沿节点。
- **玩家可读性**：屏幕上方有一条**"侵蚀推进条"**（当前 spawnFrontY 的位置），越往上推 = 越危险。

**为什么这是好的压力来源**：怪不是"变强"（血条还是薄），而是**"离你越来越近"**——缩短反应时间、压缩走位空间，天然形成紧迫感，且不破坏"虫血薄"的定位。

## 4. 反制：地堡 / 工事（Bunker）

### 4.1 规则

- **可建造区域**：英雄的**活动区 `defenseRect`（y∈[96,560]）**内，选一块空地建造。
- **建造方式**：消耗资源（金币/材料），有建造时间（有"施工中"状态，可被打断？→ 可选）。
- **覆盖半径**：以地堡为中心 ~120px 圆形/方形地块。
- **覆盖效果**：该区域**永久免疫侵蚀**（网无法长入；已存在的侵蚀被压制移除）。
- **地堡本身可被攻击**：虫族会攻击地堡（尤其毒爆/雷兽），地堡有 HP，破掉后覆盖失效、侵蚀可反扑——形成"保卫工事"的战斗目标。

### 4.2 与"堆塔"的取舍（关键）

| 投入 | 收益 | 风险 |
|------|------|------|
| 造塔/加武器 | 直接火力 | 不解决出生线推进，后期被贴脸 |
| 造地堡 | 抢土地、挡住出生线、保住安全区 | 不提供输出，纯投资未来 |
| 地堡位置 | 越靠前（越靠战场方向）挡得越多，但越容易被虫打 | 越靠后越安全但覆盖少 |

→ **同一份资源，火力 vs 地盘**，构成每局不同的构筑选择（Roguelike 的"分支"）。

### 4.3 地堡的类型（可扩展，M1 只做 1 种）

- **基础地堡（必做）**：仅"免疫侵蚀 + 少量HP"。
- *（后续）* 加固地堡（更大范围）、炮塔地堡（免疫侵蚀 + 提供火力）、治疗地堡（范围内英雄/城墙缓慢回复）。

## 5. 形象设计（视觉语言，遵循 docs/06 与 docs/08）

### 5.1 侵蚀网（地下层，画在怪物之下）

| 元素 | 构成 | 动效 |
|------|------|------|
| 节点 | **多层同心圆 + 脉动内核**（酸性绿 `#7CB342` 外环 + 亮黄绿 `#AEEA00` 芯 + 深绿暗部），中心有一枚"虫核"（像拳头大的卵） | 呼吸脉动随"距离核心远近"变化；靠近城墙的节点脉动更急（危险度） |
| 连线 | **有机脉纹**（贝塞尔曲线，粗细不均），沿线有"营养颗粒"从核心向外流动 | 颗粒沿连线朝前沿流动 = 供能方向可读 |
| 侵蚀地格 | 半透明暗绿地膜 + 边缘亮弧（蔓延感） | 已有的 creep 绘制方式，扩展为本系统 |
| 被烧断的连线 | 断口焦黑 + 飘散孢子 | 火焰命中 → 断线特效 |

> **可读性铁律**：节点虽然打不到，但**必须看得见**（弱化但不隐形），让玩家理解"出生点为什么在往前移"。半透明 + 脉纹，不抢弹幕亮度。

### 5.2 地堡（我方，画在活动区内）

| 元素 | 构成 | 动效 |
|------|------|------|
| 地堡本体 | **六边形/圆角方基座 + 城垛**（与城墙同一套"矩形/网格"语言，表明是"建造物"），我方青绿 `#35E0C3` 描边 | 施工中：半透明 + 脚手架线 + 进度环 |
| 覆盖区 | **青色网格地块**（与侵蚀的暗绿强对比），边界有"钉地"小桩 | 建成瞬间向外扩散一圈"定土"冲击环 |
| 免疫反馈 | 侵蚀蔓延到地堡边缘时，被"顶住"并回缩 | 边缘碰撞火花（青绿 vs 绿） |

> 颜色纪律：**侵蚀=酸绿、地堡/我方=青绿**——两套系统一眼可分，不新增色相。

### 5.3 虫族单位（沿用 docs/08 现有 6 种，微调）

- 幼虫群/爬虫/潜伏者/虫后/毒爆/雷兽**美术不变**（已有一版）。
- **新增表现**：
  - 从侵蚀节点出土时 → 节点处"喷发"一圈孢子 + 虫子钻出。
  - 站在侵蚀区（供能）内 → 身上有**暗绿能量脉络**发光（表示被供能=更强）；离开则熄灭。

## 6. 数值与节奏（初设，待 sim 调）

| 参数 | 初值 | 说明 |
|------|------|------|
| 节点最大数 | 24 | 上限，防止无限膨胀 |
| 长出间隔 | 波1: 12s → 波10: 4s | 逐波加快 |
| 节点 HP | 300（不可瞄准，仅地堡压制/火焰缓慢消耗） | "生命很强" |
| 供能档位 | 距核心 ≤2 跳: +30% HP/+20% 攻；≥3 跳: +10%/+8% | 越靠外越弱（鼓励玩家顶掉前沿） |
| 出生线推进步长 | 每次新节点前进 1 格（90px） | 可读的离散推进 |
| 地堡成本 | 60 金币（≈1.5 次升级卡价值） | 与"火力"形成取舍 |
| 地堡覆盖半径 | 120px | 覆盖约 1.8 个地块半径 |
| 地堡 HP | 400；被毒爆炸一次 -150 | 需保卫 |
| 建造时间 | 2.5s（施工中可被打断） | 提供操作压力 |

**波次结构（level_2_1 重排建议）**
- W1–2：教学虫海（薄血、出生靠后），让玩家习惯"清虫"。
- W3–5：侵蚀网初现（节点开始长），出生线开始前移；玩家第一次感到"不对劲"。
- W6：**解锁地堡**（教学：给你一个免费地堡会合，让你体验"钉地"）。
- W7–9：网加速，出生线逼近，玩家必须持续造/守地堡。
- W10：虫后 + 雷兽 + 全网爆发，最后一次"守住最后一块地"的验收。

## 7. 与现有代码的映射（落地指引）

| 设计要素 | 现有基础 | 改法 |
|----------|----------|------|
| 侵蚀网（节点/连线） | `session.creep: Map<key, until>`（90px 网格） | 新增 `nodes: {x,y,hp,links}[]` + `links` 图；`creep` 作为其"地格覆盖"缓存 |
| 供血供能 | `creepBenefit` 回血 2/s、CREEP_REGEN 档位 | 改为按节点供能档位给 HP 上限/攻击倍率（乘算，可读） |
| 出生线前移 | 固定 `spawnBandY` + `fromCreep` 从虫苔出生 | `spawnFrontY = min(已用出生点, 前沿节点y-余量)`；出生点绑定前沿节点 |
| 地堡 | **无** | 新增 `bunkers: {x,y,r,hp,buildLeft}[]`；建造命令来自 UI；侵蚀扩张时检测地堡覆盖则跳过/回缩 |
| 渲染 | `scene.ts` / `shapes.ts`（creep 离屏缓存） | 节点/连线层画在 creep 层之上、怪物之下；地堡画在英雄层附近；加"侵蚀推进条"到 HUD |
| 火焰断线 | `burnCreep(x,y,r)` | 保留；额外标记"连线被烧断"（临时，N 秒后重连） |

> 确定性：节点生长用现有 `Rng`（同种子可复现），只影响玩法不影响渲染随机。

## 8. 风险与备选

| 风险 | 缓解 |
|------|------|
| 玩家"看不见敌人为什么强/从哪来" | 侵蚀推进条 + 节点可见（半透明）+ 出土喷发动画 |
| 地堡被秒 → 挫败 | 地堡 HP 可升、建造有提示、被攻击时警报 |
| 节点不可打 → 玩家"无能为力"感 | 火焰断线 + 地堡压制 两条交互路径；不要让它完全无解 |
| 系统过重 | M1 只做：节点生长 + 出生线前移 + 基础地堡；连线/供能档位/地堡类型后续迭代 |

## 9. M1 最小可玩范围（建议先做这些）

1. **侵蚀节点**：可见、缓慢生长（固定节奏），从底部向城墙方向长。
2. **出生线前移**：虫子从最靠前的节点旁出土（替代固定出生带）。
3. **供能**：节点覆盖区内的虫族 HP×1.2、攻×1.15（一个档位，先不做分档）。
4. **地堡**：在活动区点选建造，覆盖区免疫侵蚀；地堡有 HP，可被破坏。
5. **HUD**：顶部一条"侵蚀推进"进度（当前出生线位置）。
6. **视觉**：节点=脉动虫核、地堡=青绿六边基座、覆盖区=青网格。

> 上述 6 项是"机制闭环"的最小集；做完即可验证核心张力（火力 vs 地盘）是否成立，再决定是否加连线/断线/地堡类型。
