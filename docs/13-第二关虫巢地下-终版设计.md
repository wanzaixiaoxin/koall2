# 13 第二章「虫巢地下」终版设计（定稿）

> 状态：**设计终版（未实现）**｜取代并收敛 docs/09、docs/10、docs/11、docs/12
> 决策基线（已与玩家确认）：
> - 胜负：**拆对方核心**，无时间限制、无波次表、无"零战果腐朽"
> - 资源：虫族=**虫核**；玩家=击杀掉落（暂称"晶屑"，见 §9）
> - 地下网络：**参考 SC2 菌毯（Creep）**，虫巢可移动
> - 核心约束：菌毯/瘤/虫巢**不能一次打死**；**武器全自动索敌（玩家不瞄准，唯一主动操作=走位）** → 机制必须"区域/走位导向"（见 §4.0）
> - 战场：一屏 1080×1920；英雄活动区 y∈[96,560]；武器射程 850~1100（覆盖大半个屏）；子弹近似无限；闪电/激光为全场 AOE

---

## 1. 设计定位（一句话）

> **这不是"塔防撑波次"，也不是"RTS 运营"，而是"用有限的注意力，压制一片永远清不干净的虫巢力场，最终打穿会跑的虫巢"。**

- **压力来源**：不是"怪太强"，而是"**虫群无限 + 菌毯永不消失 + 火力只有一份**" → **顾此失彼**。
- **玩家爽点**：弹幕清虫群（该爽的地方）+ 用走位"守住一片、放掉另一片"的地盘博弈 + 压制成功、虫巢护甲被剥穿时的"势能反转"。
- **失败体验**：被虫海淹没、菌毯活性被虫族拉满、虫巢越跑越难抓。

## 2. 胜负模型（对称对抗）

### 2.1 双核心

| 阵营 | 核心 | 位置 | 被摧毁 |
|------|------|------|--------|
| 玩家 | **基地核心**（现有城墙的"核心段"） | 底部 y≈64 | 失败 |
| 虫族 | **虫巢（Hive）** | 顶部 y≈1700~1850，**可左右移动** | 胜利 |

### 2.2 初期"谁都打不死谁"：茧壳护甲

- 双方核心初始 **茧壳护甲 = 100%**：任何输出对"护甲"的伤害 **被上限吸收**（见 §4.3），**早期无法拆家**。
- 护甲不是"血条"，而是一个 **0~100 的百分比**，只有**满足条件**才下降：
  - **虫巢护甲** 下降条件：玩家**持续压制菌毯活性**（见 §4.2）+ 击杀菌毯瘤（§4.4）。
  - **玩家核心护甲** 下降条件：虫族**摧毁玩家的设施（地堡/塔）**（见 §8）。
- **护甲 → 0 后**，核心才真正可被"常规伤害"摧毁（进入拆家期）。

### 2.3 胜负路径（多条）

1. **主路径**：压制菌毯活性 → 剥虫巢护甲 → 打穿虫巢。
2. **斩首**（可选）：虫后在场时，杀虫后 → 虫核收入骤降 → 加速剥护甲。
3. **无"软胜利/腐朽"**：玩家已取消；收敛靠 §4.5（虫核总量与活性回升的天然拉锯）。

## 3. 战场结构（一屏 + 远射程下的空间语义）

```
y=1920 ────────────────────────  虫巢活动带（可左右移动）
          ▲ 菌毯从虫巢向下/向两侧蔓延
          │
          │  ← 虫群从"最靠前的活跃菌毯瘤"涌出
          │
y=560  ────── 英雄活动区上界（可左右走位抵抗）
y=96   ────── 英雄活动区下界
y=64   ────── 玩家基地核心
```

- **纵向前移意义弱**（射程覆盖全屏）：**出生线前移不作为主压力**，仅作为"虫巢把瘤往前铺 = 虫群从更近处涌出、多方向合围"的表现。
- **横向意义强**：**虫巢左右移动** = 主攻方向变化；英雄**左右走位** = 唯一有意义的空间博弈。**横向拉锯是本作的地形核心**。

> **操作模型（决定性）**：武器全部自动索敌（`targeting=nearest`），玩家**不瞄准、不选目标**，**唯一主动操作 = 走位**。
> 因此本关一切机制都以"**你站在哪、清哪片**"驱动（区域导向），不做任何"手动指定目标"的设计。

## 4. 地下网络：菌毯系统（SC2 改编，核心）

### 4.1 三层结构

| 层 | 可否消灭 | 作用 |
|----|----------|------|
| **菌毯地面（Creep）** | ❌ 永不消失 | 判定"在菌毯上"（虫族移速×1.25）；视觉；虫族孵化的必要条件；**活性载体** |
| **菌毯瘤（Tumor）** | ❌ 打不死 | 菌毯扩张的"发动机"；**不进入索敌表**（玩家不瞄准它）；活性节点 |
| **虫巢（Hive）** | ✅ **唯一可摧毁目标** | 自带菌毯；产虫核；孵兵；可移动；有茧壳护甲 |

### 4.0 前提约束：武器全自动索敌（`targeting=nearest`）——设计必须"区域导向"

> **本作玩家不瞄准、不选目标**：所有武器自动打"最近"的敌人。
> 因此**一切"需要玩家手动针对某个具体目标"的机制全部作废**（如"抓瘤露出窗口集火"）。
> 玩家的**唯一主动操作 = 走位**（站哪、往哪移动）。所以菌毯系统必须由"**区域状态**"驱动，而不是"被瞄准的目标"驱动。

### 4.2 菌毯活性 —— 由"局部虫群密度"驱动（不是被玩家打）

> **重新定义（按自动索敌修正）**：菌毯没有血条、也不被武器直接打；它的"活性"由**它周围的虫群密度**维系。

- 每片菌毯/每个瘤维护 **活性值 a ∈ [0,100]**（按 90px 网格/区域算）。**判定依据是"密度阈值"，不是累计击杀数**：
  ```
  每个区域（90px 网格）：
    该区域存活虫群数  > 阈值 H（没压住）  → a 上升（虫在滋养菌毯）
    该区域存活虫群数 <= 阈值 L（清空/压制住） → a 下降（菌毯枯萎）
    L < 数量 <= H：a 缓变（临界）
    a 有回升基线（虫巢附近 / 有瘤的区域回升更快），始终倾向回升
  ```
- **为什么用"密度阈值"而非"击杀数"**：这样**单体武器和 AOE 武器都能压制**，只是"覆盖范围"不同——
  - **单体武器**（步枪/回旋镖）：单发伤害高 → 能快速**清空一小片**的区域 → 那片 a 掉得快，但**只能守一点**。
  - **AOE/穿透/链式**（炸弹/激光/弩/雷电）：能**同时清空一片/一条**的区域 → 广域压制，但受弹药/射速/单发伤害权衡。
  - → **没有"武器歧视"**：谁都能压菌毯，区别在"压多大范围、多快"。武器压制形态见 §4.2.1。
- **玩家的操作如何影响 a**：**只有"把某区域的虫清到阈值以下"能降 a**（自动索敌的火力天然落在最近虫群上）：
  - 玩家站在/打向某区域 → 该区域虫群被清到阈值下 → **该区域 a 下降（菌毯枯萎）**。
  - 顾不上某区域 → 该区域虫群回升过阈值 → a 回升 → 菌毯疯长、从该方向涌虫。
- **这就是"走位即决策"**：你守哪片清哪片，哪片就萎缩；放弃的一侧就反扑。

#### 4.2.1 武器压制形态表（每把武器怎么"压菌毯"）

| 武器 | 弹道形态 | 压制形态 | 压制特点 |
|------|----------|----------|----------|
| 符文步枪 | 单体直射（nearest） | **点压** | 单点快、但一次只清一小片 → 守脚下一点 |
| 穿透弩 | 直线穿透（3 层） | **线压** | 清一条走廊，走廊内密度快速降低 |
| 炼金炸弹 | 抛物线 + 落地范围爆炸 | **面压** | 一片区域瞬间清空，最强压制，但节奏慢（间隔/耗） |
| 回旋镖 | 单体往返（2 段） | **点压+来回** | 同一小片来回清，稳住一点 |
| 雷电权杖 | 连锁跳（1+链） | **散压** | 同时削几个分散点，适合打散稀疏虫群 |
| 集聚激光炮 | 直线光束（持续） | **线压（持续）** | 长期压住一条线，压活性最稳但范围窄 |

> **构筑意义**：不同武器 = 不同"版图压制形状"。玩家用"走位 + 武器组合"决定**能守住多大、多少块地盘**。AOE 不是唯一解，单体靠"高单发清空局部"同样成立。

### 4.3 全局活性 → 虫核收入 + 虫巢护甲（把"清虫"翻译成"压制"）

- **虫核收入** = Σ(各区域活性 × 系数) + 虫巢基础。
  - 玩家把大片区域清干净 → 全局活性降 → 虫核收入降 → 虫族出高级兵变慢。
- **虫巢护甲剥离**：每 10s，护甲下降量 ∝ (100 − 全局平均活性)。
  - 玩家持续维持"低活性"（清场）→ 护甲稳步剥 → 打穿虫巢。
  - 玩家松懈 → 活性回升 → 护甲几乎不掉 → 前功尽弃。
- **设计意图**：无限输出被消耗在"**持续把虫群清到密度阈值以下、维持低活性**"上。**所有武器都能做到，只是覆盖范围不同**（单体=点压、AOE=面压，见 §4.2.1）；菌毯本身不可被清除，所以不存在"一次清场就通关"。

### 4.4 菌毯瘤（不进入索敌表，玩家手动打不到也无所谓）

| 属性 | 设定 |
|------|------|
| 索敌 | **不进入武器索敌表**（不被"最近"选中） |
| 被伤害 | 只被**范围/穿透/AOE 的顺带伤害**波及（不主动打它，但 AOE 会削它） |
| HP | 有 HP；AOE 波及时会掉 HP，掉到 0 **进入休眠复活**（不是被专门打死，而是"被范围清场顺手压掉"） |
| 休眠 | 6s 后原地复活、恢复 50%，**消耗虫核**；休眠期间**其区域活性上限降低、虫核收入暂停** |
| 增殖 | 每 8s 朝"离其它源最远、优先朝城墙/两侧"扩 1 格；概率在扩张前沿长出新瘤（受总数上限约束） |
| 培育 | 瘤周围区域**活性回升更快**（这是"瘤=发动机"的体现） |

> **为什么这样自洽**：玩家不需要（也无法）专门打瘤；**AOE 清虫时顺手就把瘤周围的菌毯与瘤本身削了**——这正好奖励"用范围武器去清场"的构筑，而不需要任何手动瞄准。

### 4.5 收敛（无腐朽、无时间限制下如何不拖）

- **瘤总数上限 + 虫核总收入有限**：虫族不能无限扩。
- **活性随虫群永远回升**：玩家必须持续维护低活性，无法"清完就安全"。
- **虫巢护甲单向下降**（只会因玩家维持压制而降，虫族不能回补）→ 双方天然朝终局推进。
- **可认输**。

### 4.6 玩家反制手段（全部无需瞄准）

| 手段 | 效果 | 操作 |
|------|------|------|
| **走位清场** | 所到区域虫群被清 → 该区域活性↓ → 菌毯萎缩 | 唯一主动操作 |
| **范围/AOE 武器** | 清场效率高，顺带削瘤/压活性（对压制最高效） | 构筑选择 |
| **火焰烧地面** | 清掉地面（会回长，活性低时回得慢） | 自动命中 |
| **地堡钉地** | 覆盖区**永久免疫菌毯** | 预先建造（§8） |

> **一句话**：玩家不"打菌毯"，玩家"用清虫的方式让菌毯失去养分"。走位 = 选择放弃哪片、守住哪片。

## 5. 虫巢（Hive）——唯一能打死、且会跑

| 属性 | 设定 |
|------|------|
| 位置 | 顶部带（y 1700~1850），**左右移动**为主 |
| 移动触发 | ①定期换位（每 45~60s）；②护甲被剥到阈值（如 <40%）→ 侧向逃；③玩家逼近 |
| 移动方式 | **沿菌毯位移**，1.5s 迁徙期：**不孵兵 + 护甲+15%**（给玩家"趁迁徙打"或"被压制"的博弈）；单次 ≤ 2 格，不瞬移 |
| 茧壳护甲 | 100%→0；下降条件见 §2.2 |
| 孵化 | 虫核够 → 在最靠前的**活跃瘤**处孵兵（§6） |
| 摧毁 | 护甲 0 后，常规伤害可拆（拆家期） |

**可读性**：虫巢移动时地面裂开 + 根须蠕动 + 拖出新菌毯；HUD 顶部显示虫巢位置与朝向。

## 6. 出生机制（虫巢/瘤驱动，无波次）

### 6.1 三来源

| 来源 | 说明 |
|------|------|
| **① 瘤孵兵（主）** | 活跃（a 高）的瘤周期孵兵；**越是靠前的瘤，孵出的兵越靠前** |
| **② 虫巢孵兵** | 虫巢本体附近（守卫/应急） |
| **③ 事件孵兵** | 迁徙落地、虫后产卵、玩家逼近时的"背水一战"（一次多只） |

### 6.2 出生规则
- **只在菌毯上孵**（SC2 规则）。
- 出生点 = **最靠前、活性足够、未被地堡压制的瘤**。
- **出生预警**：瘤先"鼓胀冒泡" 0.8s → 喷发孢子 → 虫钻出（可读、可反应）。
- **孵化消耗虫核** → 虫核不足就断兵（"削发育"的直接落点）。

### 6.3 节奏（靠经济，不靠时间）
- 虫核收入 = 虫巢基础 + **Σ 菌毯瘤（活性 × 系数）** → 瘤多且活性高 → 收入高 → 出高级兵。
- 玩家压活性 → 收入低 → 只出幼虫群（弱）→ 玩家拿到窗口。

### 6.4 单位解锁（靠发育，不靠"第几波"）

| 单位 | 解锁 |
|------|------|
| 幼虫群 | 默认 |
| 爬虫 | 虫核累计收入 ≥ X1 |
| 潜伏者 | 虫巢升级 1 |
| 虫后 / 毒爆 | 虫巢升级 2（虫巢升级由虫核投入） |
| 雷兽 | 迁徙过 1 次 或 虫巢升级 3 |

## 7. 数值框架（初设，供 sim 调参）

| 参数 | 初值 | 备注 |
|------|------|------|
| 菌毯活性 a | 0~100，回升基线按区域 | 由"局部虫群密度阈值"驱动（§4.2） |
| 区域虫群阈值 | L=3 只 / H=8 只（每 90px 网格） | 低于 L 判"已压制"→a 降；高于 H→a 升 |
| 活性上涨 | 区域虫数 > H：+3/s | 虫在滋养菌毯 |
| 活性下降 | 区域虫数 ≤ L：-8/s | 压制住=枯萎（任何武器都能做到，范围不同） |
| 活性临界 | L<虫数≤H：±1/s 缓变 | 拉锯区 |
| 活性回升基线 | 瘤周边 +2/s；虫巢周边 +4/s | 发动机效应 |
| 瘤数上限 | 虫巢等级×2+3 | 防无限扩 |
| 瘤 HP | 80（被 AOE 顺带波及掉血；掉 0 休眠） | 不专门打，靠清场顺带 |
| 瘤休眠 | 6s 后复活，耗虫核 20 | 收入暂停 |
| 菌毯地面被清后重生 | 区域活性 a 决定（a=100:3s；a=8:20s） | 活性越低越难长 |
| 虫巢护甲 | 100 点；每 10s 下降 = (100-全局平均活性)/10 | 维持低活性则稳定剥 |
| 虫巢迁徙 | 45~60s 一次；迁徙 1.5s（不孵兵+护甲+15%） | 会跑 |
| 虫核收入 | 虫巢 2/s + Σ区域(活性/100 × 1.5)/s | 清场即砍收入 |
| 孵幼虫群耗费 | 虫核 5 | — |
| 爬虫/潜伏者/虫后/毒爆/雷兽 | 虫核 12/25/60/20/120 | 经济解锁 |

> 所有数值以"能跑通闭环、不爆炸"为准，最终以 sim 压测校准。

## 8. 玩家侧（对称发育 + 反制）

### 8.1 玩家资源
- **晶屑**（暂名）：击杀虫族掉落（可拾取）→ 用于**升级三选一 / 造地堡**。
- 与"火力 vs 地盘"取舍：造塔/升级 vs 造地堡抢地。

### 8.2 地堡（Bunker）
- 建造区域：英雄活动区（y 96~560）内的空地。
- 覆盖半径 ~120px；**覆盖区永久免疫菌毯**（瘤无法长入、已长被顶掉）。
- 有 HP（如 400），**可被虫族攻击**（尤其毒爆/雷兽）；破掉 → 覆盖失效、菌毯反扑。
- **M1 简化**：先给玩家固定 1~2 个地堡（不做建造 UI），验证"钉地"手感。
- 与空间语义一致：地堡是**横向拉锯的"桩"**（把某一段横向守住）。

### 8.3 玩家核心护甲下降
- 玩家设施（地堡/塔）每被摧毁 1 个 → 玩家核心护甲 -Y 档（§2.2）。
- → 虫族也有"拆发育"手段，对称。

## 9. 形象设计（视觉语言，遵循 docs/06 色板）

### 9.1 菌毯（地下层，画在怪物/弹幕之下）

| 元素 | 构成 | 动效 |
|------|------|------|

## 11. M1 最小可玩（实现清单）

1. **双核心 + 茧壳护甲**（玩家基地 / 虫巢，护甲显示）。
2. **菌毯三层**：地面（无时限 + 活性）、瘤（不索敌、AOE 顺带掉血、休眠复活）、虫巢（固定位置，暂不移动）。
3. **活性由虫群密度阈值驱动**：区域虫数 ≤ L → 活性↓ → 菌毯萎缩（任何武器都能做到，范围不同；见 §4.2.1）。
4. **孵兵**：仅在菌毯上，从最靠前高活性区域的瘤出土（幼虫群 + 爬虫两种）。
5. **活性 → 虫巢护甲**：持续维持低活性则护甲缓慢下降。
6. **地堡（固定 1~2 个）**：覆盖区免疫菌毯。
7. **胜负**：虫巢护甲+HP 归零 = 胜；玩家核心归零 = 败；**无时间限制**。
8. **HUD**：虫巢护甲条 + 虫巢位置 + （可选）全局活性条。

> 做完 8 项即闭环：**压制活性 → 剥护甲 → 拆虫巢**。虫巢移动、虫后/毒爆/雷兽、地堡建造 UI 作为 M2。

## 12. 风险与备选

| 风险 | 缓解 |
|------|------|
| 玩家"清半天虫，菌毯没感觉" | 活性可视化（菌毯亮/暗、脉动快慢）+ 清场时"菌毯枯萎"动画 + 全局活性条 |
| 全场 AOE 太强 | 让 AOE 在**虫群**上超强（爽点），且"清得越干净→压制越强"是设计意图，不再是问题 |
| 玩家"顾不过来"挫败 | 地堡/塔帮顶；活性回升速度可调；先给固定地堡降低难度 |
| **单体武器清不动虫海** | 阈值判定看"区域虫数≤L"，单体武器靠"高单发快速清空一小片"也能达标；且 M1 用"点压/线压/面压"三档验证平衡（§4.2.1），必要时下调 L 或给单体武器"击杀溅射"补足 |
| 数值失控（玩家 DPS 暴涨） | 因为压制靠"清虫维持"而非"打菌毯"，高 DPS = 清虫更快 = 压制更强的**正反馈**，不会破坏菌毯不灭性 |
| 拉锯过久 | 虫巢护甲单向下降 + 虫核/瘤上限 → 天然朝终局推进 |
