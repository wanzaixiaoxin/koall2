# 07 弹道行为库（Trajectory & Behavior Library）

> 目标：把子弹/投射物的"运动轨迹 + 形态行为"抽象成**结构化、可声明配置、可组合**的体系，
> 让武器设计、卡牌设计、AI 内容生成都能以最小成本调用。
> 代码入口：`src/gamecore/trajectory.ts`（运动层）、`session.ts`（世界交互层）、`data/types.ts`（配置类型）。
> 测试：`npm test` 中 `T-`（运动基元）/`C-行为`（连锁）/`S-`（光束连线）前缀的断言。

---

## 1. 四层体系总览

```
┌─ 4 特殊形态 ────────────────────────────────────────────┐
│  Beam 光束（锚定主人持续射线）  Link 两点/多点固定连线      │  session.segments
├─ 3 世界交互（命中后行为，HeroAffixes 词缀）────────────────┤
│  chain 连锁 · bounce 弹射 · pierce 穿透 · split 击杀分裂    │  session.collide*
├─ 2 生命周期（何时消亡/触发效果）───────────────────────────┤
│  range 射程 · duration 时间 · nearOwner 回到主人 · 落地     │  TrajectoryResult.alive
├─ 1 运动基元 Motion（位置如何随时间变化）──────────────────┤
│  straight / homing / parabola / spiral / zigzag /         │  trajectory.ts
│  waypoints / hover / phased（阶段机，可组合出任意复合形态）  │
└──────────────────────────────────────────────────────────┘
```

**设计原则**
- 每层只依赖下一层的接口，上层（武器/卡牌/AI 生成）只接触第 1 层的声明式配置 + 第 3 层的词缀 ID；
- 全部确定性（同种子可复现）；运动基元零世界状态，世界查询经 `MotionContext` 注入；
- 组合安全：衍生/重定向一律按"运动配置快照"重建（`ProjectileRuntime.motionCfg`），保证后拿的词缀不废先拿的效果。

## 2. 运动基元目录（第 1 层）

统一接口：`update(x, y, ctx: MotionContext) → { x, y, alive, height? }`

| 基元 | 配置 | 说明 | 典型用途 |
|------|------|------|----------|
| `straight` | speed, range | 匀速直线，射程尽消亡 | 步枪/箭矢 |
| `homing` | speed, range, turnRate, duration, retarget, home? | 追踪：转向角/时长/重索敌三限制；home=true 追踪主人（飞盘返回段） | 追踪弹 |
| `parabola` | speed, range, peak? | 飞向发射时锁定落点，到达即"落地"消亡（触发落地效果）；返回 height 供渲染画弧 | 炸弹/毒雾瓶 |
| `spiral` | speed, range, angularSpeed, radius | 主轴前进 + 垂直正弦摆动（相位连续） | 钻头弹/旋转刃 |
| `zigzag` | speed, range, frequency, amplitude | 高频蛇形波 | 波动弹/闪避弹道 |
| `waypoints` | speed, points[], loop? | 沿路径点折线飞行（可走回头路） | 巡逻弹/回旋花式 |
| `hover` | — | 原地悬停 | 备用基元（回旋镖已改为立即折返） |
| `phased` | phases: [{motion, until}] | **阶段机**：按 距离/时间/近主人 切换运动基元 | 见下方预设 |

**阶段机结束条件（PhaseUntil）**：`distance` 累计位移 ｜ `duration` 累计时间 ｜ `nearOwner` 距主人距离。

**内置预设**
- `frisbeeConfig(speed, outRange, returnSpeed, turnRate?)`：飞盘 = 飞出(distance) → 立即折返回主人(nearOwner)；
- 例：回旋镖 = `phased[直线飞出 350 → homing(home) 折返]` + 穿透 99 + 重击冷却 0.25s（**去/回各一刀**）。

**工厂**：`createTrajectory(cfg: TrajectoryConfig, launch: {dirX, dirY, target?})` —— 配置即数据，可进 JSON（武器表 `motion` 字段 / AI 生成内容）。

## 3. 世界交互目录（第 3 层，词缀）

| 词缀 | 行为 | 组合规则 |
|------|------|----------|
| `chain` 连锁闪电 | **非子弹**：索敌后从炮口直接劈向目标，再瞬时跳跃最近未命中目标（1+等级 击，×0.8/跳），发 `onChain{points}` 渲染折线电弧 | 每次开火/连射都是独立落雷；不触发分裂（无弹体） |
| `bounce` 弹射 | 命中后**物理重定向**到最近未命中目标（继续飞行、可再命中） | 按 motionCfg 重建 → 保留追踪 |
| `pierce` 穿透 | 穿过目标继续飞（每穿一个伤害-0 递减由武器配置） | 与齐射/连射天然叠加 |
| `split` 分裂 | 击杀时衍生 2 发（±0.5rad，伤害×0.5） | 衍生弹继承追踪/火/冰/破甲，不继承 split/bounce/blast（防指数爆炸） |
| `blast` 爆破落地 | 子弹消亡（射程尽/命中/连锁完）时产生 瞬时AOE + 持续伤害圈 | 与一切消亡路径叠加 |

## 4. 特殊形态（第 4 层，非抛射物）

统一结构 `SegmentField {ax,ay,bx,by,width,dps,until,damageType,followOwner?,angle?,length?}`，
对**线段胶囊体**内的怪物每帧结算 dps（`distToSegment < width/2 + radius`）。

| 形态 | 锚定方式 | 说明 | 调用 |
|------|----------|------|------|
| **光束 Beam** | `followOwner=true`：端点 A 跟随英雄，按 angle/length 延伸（可每帧转向→扫射） | 即时命中 + 持续 tick，无弹体 | 武器类型或技能；测试 `session.debugBeam(angle, length, dps, duration)` |
| **连线 Link** | 两端固定（两点/多点固定连接） | 区域封锁：电网/火墙/激光栅栏 | 测试 `session.debugLink(ax,ay,bx,by,dps,duration)` |

> 多点连接 = 多个 SegmentField 共享 until，渲染层折线相连。
