# 03 技能与升级卡设计

> 升级卡是 roguelike 构筑的核心交互。设计原则：**每次三选一都要构成真实取舍**——不是"哪个强拿哪个"，而是"我现在缺什么、这把想玩什么"。

---

## 1. 升级触发与流程

```
经验宝石 → 经验条满 → 升级
  → 暂停战斗（0.5s 慢动作过渡）→ 弹出 3 张卡
  → 选择 → 即时生效 → 恢复战斗
```

- 若武器/辅助已满级，对应卡不再出现（自动过滤）。
- 提供 **1 次重roll / 局**（第二里程碑可加"ban 卡"机制）。
- Boss 关击败 Boss 额外送一次"稀有以上必出"的三选一。
- 波间休整期：战斗停火数秒喘息；经验为**击杀自动吸收**（无拾取操作）；每 2 波之间至少保证一次升级节奏点，让构筑成长与波次压力同步爬升。

## 2. 卡牌类型与稀有度

### 2.1 卡牌类型（统一体系：效果 × 目标声明）

| 类型 | 维度 | 内容 | 示例 |
|------|------|------|------|
| `bullet` 子弹卡 | 武器弹道参数 | 齐射/连射/弹速/伤害/射程 | 齐射、连射（步枪专属）；强装药（公共） |
| `wall` 城墙卡 | B 类：城墙 | 城防上限 / 立即修复 | 加固城墙、紧急修缮 |
| `form` 形态卡 | 形态机制 | 追踪/弹射/分裂/破甲/爆破/连锁闪电 | 追踪弹、连锁闪电 |
| `element` 元素卡 | 元素赋予与加持 | 赋予：武器改属元素+解锁骑士效果；加持：强化该元素的伤害/减速 | 火焰弹/寒冰弹（赋予）；烈火/严寒（加持） |
| `passive` 属性卡 | 公共 | 攻击/攻速/暴击/全伤（作用于所有武器） | 力量、急速、鹰眼 |

### 2.2 目标声明与卡池门控（核心机制）

每张卡可声明 `target`（缺省 = 公共），进入三选一候选前统一过滤：

| target | 门控规则 | 示例 |
|--------|----------|------|
| `any` 公共 | 始终可选；效果作用于全部武器/英雄 | 强装药、力量、连锁闪电 |
| `weapon` 武器专属 | 仅当持有该武器时可选；效果只作用于该武器 | 齐射/连射/急速弹/长枪管 → 符文步枪 |
| `element` 元素专属 | 仅当某武器已携带该元素时可选 | 烈火（需火）、严寒（需冰） |
| 元素赋予 | 武器为默认元素（未被赋予过）时才可赋予；**一武器一元素，互斥** | 火焰弹、寒冰弹 |

由此形成构筑循环：**武器专属卡强化手感 → 公共卡补数值 → 赋予卡给子弹上元素 → 元素加持卡把该元素养肥**。
多武器英雄（M2 辅助单位实装后）同规则自动生效：每把武器独立携带元素/词缀/骑士，卡牌按目标分发。

### 2.2 稀有度

| 稀有度 | 颜色 | 效果定位 | 基础出现概率（随关卡微调） |
|--------|------|----------|------------------------------|
| 普通 | 白 | 数值 +10%~20% 或低阶词条 | 60% |
| 稀有 | 蓝 | 数值 +25%~40% 或中阶词条（穿透+1 等） | 28% |
| 史诗 | 紫 | 机制级词条（弹射、分裂、双发） | 10% |
| 传说 | 金 | 质变词条（子弹爆炸、连锁翻倍） | 2% |

**保底机制**：连续 6 次无稀有以上 → 下一次必出稀有以上（防脸黑，玩家感知友好）。

## 3. 武器升级卡的具体设计

每把武器 Lv1~8 的升级路线在配置表中定义，示例（符文步枪）：

| 等级 | 升级内容 | 稀有度 |
|------|----------|--------|
| Lv2 | 伤害 +20% | 普通 |
| Lv3 | 每次 2 发 | 稀有 |
| Lv4 | 攻击间隔 -15% | 普通 |
| Lv5 | 穿透 +1 | 稀有 |
| Lv6 | 伤害 +30% | 稀有 |
| Lv7 | 每次 3 发 | 史诗 |
| Lv8 | **超武进化**（需辅助"神枪手" + 被动"快速装填"） | 传说 |

## 4. 卡池（configs/cards.json 为准，20 张）

- **武器专属（步枪）**：齐射 +1 / 连射 +1 / 弹速 +20% / 射程 +15%
- **公共子弹**：强装药（所有武器伤害 +15%）
- **城墙**：加固城墙（上限 +30% 并得等额城防）/ 紧急修缮（+300）
- **形态**：追踪弹、弹射、分裂弹、破甲弹、爆破落地、连锁闪电（落雷）
- **元素赋予**：火焰弹（火 + 灼烧骑士 0.25/s）、寒冰弹（冰 + 12% 减速骑士）——互斥，一局一元素
- **元素加持**：烈火（灼烧 +15%/级，需火）、严寒（减速 +6% 与时长 +0.5s/级，需冰）
- **公共属性**：力量/急速/鹰眼/狂暴/专注

> 叠加与继承规则：所有效果**只增不减**；分裂/弹射衍生弹继承追踪与元素骑士，不继承分裂/弹射/爆破（防指数爆炸）；灼烧重复命中只刷新时长不叠加（叠加需未来专门卡牌）。

## 5. 特殊卡 / 技能卡

- **应急治疗**：回 30% HP（血量 <40% 时概率提升；MVP 英雄无 HP，此卡替换为"紧急修城"）
- **紧急修城**：恢复城防 25%（仅城墙血量 <50% 时进入卡池，且权重提升）——MVP 城墙唯一主动回复手段
- **金币磁石**：全场掉落物飞向你（Boss 战后必出一张）
- **弹幕时刻**（一次性技能）：3 秒攻速 ×2
- **炸弹清屏**：全屏 200 伤害 + 大击退（仅精英/Boss 有抗性时可用）
- **复活十字架**：死亡时满血复活一次（整局限购 1 次，第 2 章后解锁）

## 6. 刷新权重算法（防止构筑单一化）

```
卡池 = 过滤已满项后的所有候选
权重(卡) = 基础权重 × 类型系数 × 新鲜感系数
新鲜感系数 = 已持有同类卡越多，该类出现率越低（衰减 20%/张）
```

> 即"鼓励多拿新武器，但不强制"——纯堆一把武器超武流也应可行，只是风险集中。

## 7. 辅助单位卡

- 辅助 Lv1 获得（自选 1/3），之后升级卡池会混入其专属强化：新武器形态 / 增益光环 / 献祭爆弹等分支。
- 辅助满级（Lv5）后可解锁"觉醒"：选一个方向强化（第二里程碑）。

## 8. UI/UX 要求

- 三选一卡片：图标 + 名称 + 稀有度边框 + 当前等级/效果对比（"Lv2 → Lv3：伤害 14→18"）。
- 已持有卡显示"已拥有"角标与新效果的**差量说明**。
- 选择支持键盘/触屏滑动，确认有音效 + 粒子反馈。
