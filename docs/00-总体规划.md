# 《英雄守卫战》（暂定名）总体规划

> 类型：竖屏底部防守射击 Roguelike（参考框架：《向僵尸开炮》× 吸血鬼幸存者构筑）
> 引擎：Cocos Creator 3.x + TypeScript
> 平台：优先移动端（微信小游戏 / 原生），兼容 H5

---

## 1. 一句话概念

玩家控制一名**主英雄**，在**屏幕底部防守区域**内自由移动并自动攻击，携带最多 **3 个辅助英雄/单位**协同作战；怪物从屏幕上方一波波向下进攻，抵达最下方一排**城墙**后驻留攻击——**城墙血条耗尽 = 城破失败；消灭本关所有波次的怪物 = 胜利**。通过**关卡内升级三选一卡牌**构筑 Build，逐关推进章节。

## 2. 核心体验支柱（Pillars）

| 支柱 | 说明 | 对设计的约束 |
|------|------|--------------|
| 爽快的割草感 | 成片的怪物被弹幕、爆炸、连锁闪电清掉 | 同屏怪物 100~300；投射物必须对象池化 |
| 构筑深度 | 武器 × 辅助 × 升级卡的组合产生质变 | 武器可进化（超武）；辅助单位有流派羁绊 |
| 决策压力 | 三选一升级卡、走位补漏 or 抢经验、修城资源取舍 | 每次升级都要"贪与稳"的权衡 |
| 短局节奏 | 单局 8~12 分钟，随时可暂停退出 | 关卡 = 固定波次防守 + 收尾精英/Boss 波 |

## 3. 核心循环（Core Loop）

```
选主英雄 + 3 辅助
    ↓
进入关卡（守卫城墙）→ 底部区域走位输出、补漏 → 击杀怪物掉落经验宝石
    ↓
升级 → 三选一升级卡（新武器 / 强化 / 辅助技能 / 属性）
    ↓
逐波清剿 → 波间休整拾取 → 精英波 / 收尾 Boss 波
    ↓
全波次消灭 = 胜利 / 城墙血条耗尽 = 城破失败
    ↓
结算（金币、材料、星级）→ 局外成长 → 挑战更高章节
```

## 4. 差异化卖点

1. **主英雄 + 3 辅助编队**：辅助单位是有独立 AI 和武器的"英雄单位"（不是纯被动），可形成流派羁绊（如 3 法师 = 元素过载）。
2. **武器合成超武系统**：武器满级 + 指定辅助/被动 = 进化武器，进化条件与辅助单位绑定，强化编队感。
3. **章节式关卡制 + 城墙星级**：不是无尽生存，而是"普通关 ×N 波 + 精英波 + Boss 收尾"的章节结构；按剩余城防血量评 1~3 星，三星是复玩与炫耀动力。
4. **多路压墙的补漏操作**：怪物分多路同时压向城墙，英雄在底部区域左右补位，操作量来自"防漏"而非"躲弹幕"。

## 5. 范围控制（MVP 定义）

**MVP 必须有的（第一里程碑）：**
- 竖屏单屏竞技场：英雄在底部防守区域移动（矩形范围钳制）+ 最下方一排可被破坏的**城墙**（整排共享一条城防血条）
- 1 名主英雄（远程）、3 个辅助单位
- 4 种基础武器（子弹、箭矢、炸弹、回旋镖）
- 固定波次系统：10 波/关基准；经验/升级/三选一卡牌（含武器进化）；波间休整
- 3 种普通怪 + 1 种精英 + 1 个 Boss（收尾波）
- 1 个章节的 3 个关卡（普通波次关 ×2 + Boss 关）
- 基础对象池、伤害飘字、掉落（经验宝石/金币/血瓶）、城墙受击反馈与城破/胜利结算
- 引擎解耦架构：核心逻辑零 Cocos 依赖，Node 可无头模拟整局（AI 自动创作的前提，见 05 文档）
- "优雅几何"美术：初始版本全部几何图形绘制 + 高级动效，禁止位图素材（规范见 06 文档）

**MVP 之后：**
- 流派羁绊、更多武器与超武、更多章节、局外天赋树、波间商店/事件、英雄 HP 困难模式、每日挑战、图鉴
