# 10 第二章「虫巢地下」胜负模型重构：对称发育 · 以消灭对手为目标（无时间限制）

> 状态：设计稿（未实现）｜ 依赖：docs/09（侵蚀网/出生线/地堡）、docs/08（虫族单位）
> **本文修订 docs/09 的底层胜负模型**——从"守墙撑过 10 波（有时间轴）"改为"**双方对称对抗、消灭对手、无时间限制**"。

---

## 1. 这次变更的本质（先说清）

| 维度 | 旧模型（现实现） | 新模型（本设计） |
|------|------------------|------------------|
| 胜负条件 | 撑过 10 波 = 胜；墙破 = 败 | **消灭对方"主巢/核心" = 胜**；己方核心被毁 = 败 |
| 时间 | 每波 `durationSec` 定时刷怪 | **无波次计时**，一切由"双方发育速度"决定 |
| 敌人 | 被动等刷的虫潮 | **会发育、会扩张、会反制的对手**（虫巢 AI） |
| 初期平衡 | 第 1 波总是弱 | **双方都"打不死对方"，只能互相削发育** |
| 玩家节奏 | 波次卡点 | **自由节奏**：你可以快攻、可以憋发育、可以骚扰 |

**核心体验**：这是一盘**"双人生长竞速 + 拆家"**，不是塔防。像《星际》的人虫对拆，但保留本作"英雄 + 弹幕 + 卡牌成长"的爽感。

---

## 2. 双方对称结构

### 2.1 双方各有一个"核心 / 主巢"

| 阵营 | 核心 | 位置 | 被消灭 = |
|------|------|------|----------|
| 玩家 | **英雄基地 / 城墙核心**（= 现有城墙的"核心段"升级） | 底部 `y≈64` | 失败 |
| 虫族 | **虫巢主核（Hive Core）** | 场地最深处 `y≈1820`（原出生带位置） | 胜利 |

> 关键：**玩家现在有"进攻目标"**——不是永远挨打，而是要把火力/走位推进到虫巢主核。

### 2.2 初期"谁都打不死谁"的保证机制（对称护甲）

- 双方核心初始都有**"初生护甲 / 茧壳"**：极厚的护盾/低攻击抗性，使**早期任何输出都无法在短时间内摧毁核心**。
- 护甲随**时间/发育**逐渐减薄（或需要"先摧毁对手的发育设施"才能破甲）。
- 这样保证：**开局双方都只能"削发育"，不能直接拆家**——正是你要的"一开始都无法轻易消灭对手"。

### 2.3 发育（经济）系统：局内双资源

为支撑"发育竞速"，需要**局内经济**（现有只有经验→升级卡）：

| 资源 | 来源 | 用途 |
|------|------|------|
| **晶核（Crystal）** | 击杀敌方单位掉落 / 控制侵蚀节点产出 | 升级卡、造塔、造地堡 |
| **虫核残渣（Biomass）**（虫族侧同名资源，AI 内部用） | 虫巢节点产出、吃虫苔 | 虫族扩张/孵兵/升级 |

- **双方都在"产资源→变强"**：玩家靠英雄清怪 + 占节点；虫族靠侵蚀网产资源。
- **"削弱对手发育"= 本作的进攻手段**（见 §4）。

## 3. 胜负与"无法轻易消灭"的规则

### 3.1 胜利路径（多条，避免单一）

1. **拆家**：摧毁虫巢主核 → 胜（主路径，后期）。
2. **斩首**：击杀虫后（若虫后在场且是"核心单位"）→ 大幅削弱虫巢，不直接胜但加速。
3. **发育碾压**：经济与科技领先到虫族"无力反抗"（软胜利，见 §3.3）。

### 3.2 破甲机制（把"打不死"变成"要先把对手打瘸"）

> 核心创新：**主核不是"血条硬"，而是"有前置条件"**。

- 双方主核初始 100% 护甲 → **只能被"发育设施"打掉护甲**：
  - 玩家侧：摧毁虫族的**侵蚀节点/孵卵巢**，每毁一个 → 虫巢护甲 -X%。
  - 虫族侧：虫族会攻击玩家的**地堡/生产建筑**，每毁一个 → 玩家核心护甲 -X%。
- 护甲 < 阈值后，主核才真正可被输出。**这天然形成"先破发育、再拆家"的两阶段节奏**，且双方对称。

### 3.3 软胜利 / 崩盘条件（避免"无时间限制 = 无限拖"）

无时间限制必须有**收敛机制**，否则会拖成僵局：

| 机制 | 说明 |
|------|------|
| **资源枯竭** | 节点/晶矿总量有限，占满后先到先得 → 经济战有终点 |
| **发育上限** | 卡牌/科技有上限，双方最终到达同一档 → 拼操作/存量 |
| **主核自动崩解** | 若一方**长时间（如 6 分钟）零战果**（无击杀/无占点），其核心开始"腐朽掉血" → 强制推进，逼玩家做决策 |
| **投降/认输** | 允许玩家在明显劣势时结束（不强制拖） |

## 4. 双方"削弱对手发育"的进攻手段（对称设计）

| 玩家 → 虫族 | 虫族 → 玩家 |
|---|---|
| 击杀虫族单位（断其兵源） | 虫群冲击城墙/基地（消耗你） |
| **烧断侵蚀连线**（切断供能，火系） | 侵蚀蔓延（顶掉你的可用地） |
| **用地堡"钉地"**（压缩虫巢可扩张空间） | **攻击你的地堡/生产建筑**（摧毁后侵蚀反扑） |
| 深入推进，压迫虫巢前沿节点 | 出生线前移（贴脸压制你） |
| 抢晶矿节点 | 抢占/封锁你的资源点 |

> 关键：**这些都不是"一次性打死对方"，而是"让对方发育变慢"**——完全对应"可以削弱对手的发育"。

## 5. 与 docs/09（侵蚀网）的融合

docs/09 的侵蚀网**从"敌方单方面扩张的战场改造"，升级为"虫族的发育引擎 + 它的'经济/地盘'"**：

| docs/09 概念 | 在新模型里的角色 |
|---|---|
| 侵蚀节点 | 虫族的**资源点 + 出生点 + 护甲护符**（毁节点 = 削虫族经济 + 破主核护甲） |
| 出生线前移 | 虫族的**进攻压力**（发育越好，出生线越前） |
| 供血供能 | 虫族的**经济加成**（节点产资源、覆盖内强化） |
| 地堡 | 玩家的**地盘反制 + 防侵蚀**（同时是虫族要拆的目标） |
| 虫巢主核 | **胜利目标**（新） |

**新增**：玩家侧也要有"生产/发育设施"（塔、晶矿采集点、地堡），让虫族有东西可攻击——形成真正的**对拆**。

## 6. 关卡结构（替代 10 波时间轴）

### 6.1 无波次表 → 改为"阶段（Phase）"，由**状态**触发而非时间

| 阶段 | 触发条件 | 内容 |
|------|----------|------|
| **P1 初生** | 开局 | 双方核心茧壳满护甲；虫族开始长节点；玩家开始清虫/占点 |
| **P2 发育** | 玩家经济达 X 或虫族节点达 Y | 虫族解锁爬虫/潜伏者；双方开始互拆设施 |
| **P3 破甲** | 任一，摧毁对方若干发育设施 | 主核护甲开始掉落；虫族出虫后/雷兽 |
| **P4 决战** | 主核护甲 < 阈值 | 双方主核可被输出，进入拆家期 |

> **没有"第几波"，只有"局势到了哪一步"**——完全去掉时间轴。

### 6.2 难度=AI 发育策略，不是刷怪数量

- 虫巢是**有限状态 AI**：按"自身经济/玩家威胁"决定**扩张 / 孵兵 / 进攻 / 防守**。
- 玩家可以**快攻打断它发育**（趁它没出兵直捣节点），或**憋后期**正面拆家——两条路都成立。

## 7. 与工程实现的映射（供开发参考，不含前端）

| 变更点 | 现状 | 需要新增 |
|---|---|---|
| 胜负 | `result` 由 `wallHp<=0` / 波次打完 | 改为**主核存在性**判定：`enemyCore.hp<=0 → victory`，`playerCore.hp<=0 → defeat` |
| 波次 | `level.waves` + `buildSchedule` 时间轴 | 改为**阶段状态机** `phase: P1..P4`，由事件（经济/节点/设施）驱动 |
| 虫族 AI | 无（按表刷） | 最小 `HiveAI`：每 tick 按经济做 `expand/spawn/attack/defend` 决策 |
| 经济 | 只有经验 | 新增 `crystal`（玩家）/`biomass`（虫族）；掉落/占点产出 |
| 主核护甲 | 无 | `coreArmor` 双端；按"对方设施存活数"连接 |
| 设施 | 仅城墙 | 玩家侧：塔/地堡/采集点；虫族侧：侵蚀节点/孵卵巢 |
| 收敛 | 波次结束 | 资源枯竭 + 发育上限 + 零战果腐朽 + 认输 |

## 8. M1 最小可玩范围（把"对拆"跑起来）

1. **双核心**：玩家基地（底部）+ 虫巢主核（顶部），各有 HP + 茧壳护甲。
2. **初期不可拆**：茧壳使双方 3 分钟内都无法直接摧毁对方核心。
3. **经济**：击杀掉落"晶核"，可花在升级卡 / 造地堡。
4. **虫族最小 AI**：持续长侵蚀节点（产虫、产资源）；周期性冲击玩家。
5. **破甲前置**：摧毁 3 个侵蚀节点 → 虫巢护甲归零；虫族摧毁 1 个玩家地堡 → 玩家核心护甲 -1 档。
6. **胜负**：虫巢主核 HP 归零 = 胜；玩家核心归零 = 败；**无时间限制**。

> 做完这 6 项即可验证"**双方成长竞速 + 拆家**"是否成立。波次表、复杂 AI、多设施类型都是后续迭代。
