# 06 美术与产品统筹规划

---

## 一、美术规划

### 1. 风格定调："优雅几何"（Neo-Geometric）
- **方向**：初始版本**不使用任何位图素材**，全部由几何图形（圆/三角/矩形/圆角多边形 + 渐变 + 发光）构成——程序绘制为主、少量 SVG 为辅。**几何 ≠ 简陋**：设计感来自形状语言、克制的配色与高级动效三条纪律。
- **三条美学纪律**：
  1. **形状语言统一**：友方 = 圆与圆角（亲和），敌方 = 三角与尖角（侵略），城墙/场景 = 矩形与网格（稳定）；
  2. **克制的配色**：深色夜空底（#12142B 系）+ 每章一个点缀主色（第 1 章：荧光青 #35E0C3）+ 敌方互补警示色（珊瑚橙 #FF6B57）+ 4 状态色（火 #FF5A3C / 冰 #4FC3F7 / 雷 #B388FF / 毒 #7CB342）；**全游戏色板 ≤ 12 色**，同屏主色 ≤ 3；
  3. **生命力来自动效而非贴图**：squash & stretch、拖尾、弹性缓动、碎裂粒子——"几何图形 + 高级动效 = 设计感"。
- **战斗可读性铁律**（不变）：玩家 > 弹幕 > 精英/Boss > 小怪 > 场景（亮度/尺寸/描边逐级递减）；受击闪白全覆盖；投射物高亮描边。
- **分辨率基准**：1080×1920 竖屏；几何资产矢量无限缩放，无需多倍图。

### 2. 元素几何设计规范（设计稿 → 程序绘制）

| 元素 | 几何构成 | 动效要点 |
|------|----------|----------|
| 主英雄 | 正三角机身 + 圆形核心 + 双圆角翼 | 移动前倾；射击后坐 2px 回弹；待机呼吸浮动（±3px） |
| 辅助单位 | 小一号几何图腾：法师=菱形、射手=五边形、坦克=圆角方块 | 环绕英雄带相位差浮动；施法时核心亮度脉冲 |
| 城墙 | 底部圆角矩形城垛序列（分段，便于破损） | 受击段 3px 抖动；按 100/70/40/20% 四档缺角；<30% 血整体红光呼吸 |
| 史莱姆 | 圆角方块 | squash 弹跳前进，死亡压扁再碎裂 |
| 野狼 | 尖三角 + 尾线 | 冲刺拉伸 1.3×，前摇预警线闪红 |
| 投矛手 | 梯形 + 长矛线段 | 投矛时后仰 15°，矛旋转飞出 |
| 荆棘龟 | 六边形 + 周圈刺点 | 缩壳（刺外张）时免伤提示 |
| 分裂菇 | 三个叠圆 | 死亡分裂：大圆裂为两小圆弹出 |
| 夜行蝙蝠 | 双对三角 | 扑翼缩放 0.8~1.2×，蛇形轨迹带残影 |
| 精英 | 同族形状 ×1.6 + 双层描边脉冲 + 词缀色光环 | 词缀触发时光环爆闪 |
| Boss 树人 | 多层三角嵌套躯干 + 旋转几何外环 | 阶段切换：全屏震动 + 色温转冷 + 外环碎裂重组 |
| 投射物 | 子弹=发光圆点+短线拖尾；箭=线段+箭头；炸弹=圆+摆动引线；回旋镖=弧形双翼 | 统一 60~120ms 出生缩放；拖尾统一 80ms 渐隐 |
| 经验宝石 | 菱形（白 1 / 蓝 5 / 金 20） | 掉落弹跳 2 次静止；磁石吸附时加速飞向英雄 |
| 卡牌 | 圆角矩形 + 稀有度描边（白/蓝/紫/金）+ 几何符号图标 | 弹出弹性 300ms；选中时描边流光 |

### 3. 动效规范表（程序实现，参数集中配置）

统一由适配层 Tween 实现，参数集中在 `configs/art-style/fx-config.json`，美术调参不改代码。

| 动效 | 时长 | 缓动 | 说明 |
|------|------|------|------|
| 受击闪白 | 80ms | 线性 | 全元素覆盖，优先级最高 |
| squash & stretch | 120ms | easeOutBack | 怪物移动/死亡通用 |
| 升级选卡 | 300ms | 弹性 | 卡片弹出 |
| 城破 | 1.2s | 0.3× 慢动作 | 城墙碎裂 + 屏幕渐黑 |
| 屏幕震动 | 100ms / 300ms | 衰减 | 普通命中 3px / Boss 技 8px |
| 预警圈（dash/落石） | 与技能前摇一致 | 线性 | 红圈 + 填充进度 |

### 4. 资产清单（几何风格版，按里程碑分批）

| 批次 | 内容 | 形式 |
|------|------|------|
| M1 | 英雄、史莱姆、子弹、宝石、城墙段、地面网格背景 | 全部程序 Graphics 绘制 + fx-config |
| M2 | 怪物 5 种几何形态、投射物 4 种、精英光环、卡框 4 稀有度、爆炸/分裂粒子 | 程序绘制 + 少量 SVG |
| M3 | Boss 嵌套几何体、城垛破损 4 档、宝箱、UI 全套、章节选择/结算界面 | SVG 图标库 + 程序动效 |
| M4 | 新手引导动效、UI 动效精调、商店图标 | — |

- 音频计划不变：BGM 章节 1 首循环 + 战斗/升级/Boss 三态切换；音效优先打击感（命中、爆炸、升级、城破警报）。

### 5. 管线与验收
- 几何资产 = 绘制代码 + 配置，**不进图集、包体近零、天然合批**——与 05 文档性能策略互相成就。
- 规范三件套存 `configs/art-style/`：**palette.json（色板）/ shapes.md（形状语言）/ fx-config.json（动效参数）**，美术与程序共用同一份。
- **"几何≠简陋"验收 checklist**（每个里程碑过美术 Gate 时逐项打勾）：
  1. 每个元素至少有入场/待机/受击/死亡之一专属动效；
  2. 同屏任意时刻主色 ≤ 3，全游戏色板 ≤ 12；
  3. 受击闪白全覆盖（含城墙分段）；
  4. 截图给不了解项目的人看，能说出"这是设计过的"。

## 二、产品规划

### 1. 商业化/留存模型（轻量，先做留存后做变现）
- **局内**：纯单机体验，无内购打断（IAA 模式）。
- **变现**：复活（看广告）、双倍结算金币、每日免费抽辅助（激励视频）。Banner 仅出现在非战斗界面（结算/主界面）。
- **留存**：每日任务（击杀 X 只/通关 1 次）、每日挑战关（固定种子全局排行，第二里程碑）、图鉴收集、三星追全成就。

### 2. 版本路线图
| 版本 | 内容 | 周期 |
|------|------|------|
| V0.1 原型 | M1 内容 | 3 周 |
| V0.5 封闭测试 | M2+M3（第 1 章完整） | 6 周 |
| V1.0 首发 | 第 1~2 章、局外成长、广告点、引导 | +3 周 |
| V1.1~1.3 | 每 3~4 周一章 + 新武器/辅助流派 + 活动关 | 持续 |

### 3. 数据指标（埋点需求，开发排期要留时间）
- 关卡漏斗：每关开始/胜利/城破分布 → 定位难度断崖。
- 卡牌选取率/胜率 → 验证卡牌平衡。
- 局时长、升级速度曲线、城破原因分布（哪一波漏怪 / 精英未处理 / Boss 技能命中城墙）。
- 广告点转化率（复活接受率）。

## 三、团队分工与协作节奏

### 1. 角色分工（建议最小配置 4~5 人）
| 角色 | 职责 | 关键交付 |
|------|------|----------|
| 制作人/策划 1 | 系统设计、数值、关卡节奏 | 本套设计文档落地、配置表维护、AI 生成意图与抽检 |
| 程序 2 | 客户端主程（gamecore/架构）+ 程序（adapter/UI/工具链） | 按 M1~M4 里程碑；sim/校验/AI 流水线工具 |
| 美术 1 | 几何风格规范、UI、动效参数调优 | art-style 三件套 + 各里程碑视觉 Gate |
| 测试兼运营 1 | 测试 + 社区/数据 | 每里程碑回归 + 数据周报 |

### 2. 协作机制
- **每周节奏**：周一版本会（对里程碑进度）→ 周三可玩构建（任何人随时能玩最新版）→ 周五手感/数值评审（策划+程序+测试各打一局，记录问题清单）。
- **配置表共管**：策划（或 AI）改数值走 Git PR，程序只审 schema 不审数值；数值变更必须附 sim 报告。
- **文档即契约**：本 docs/ 目录是策划-程序-美术对齐的唯一事实来源，设计变更必须先改文档再开发；程序实现发现设计漏洞 → 文档修订评审后再改代码。
- **手感优先级仲裁**：任何"性能 vs 手感"冲突，先保手感（降画质不降手感）。
- **AI 创作边界**：AI 产出物一律经 schema 校验 + sim 试玩报告 + 人类抽检三重门，任何人可在 PR 中一票打回。

### 3. 里程碑准入/准出标准（Gate）
| 里程碑 | 准出标准 |
|--------|----------|
| M1 | sim 与真机数值一致；程序验收 60fps 无崩溃；策划验收：移动+射击手感通过 |
| M2 | 同屏 150 怪 45fps（小游戏）以上；三选一每次构成真实取舍（测试 10 人盲测）；AI 波次表 10/10 过检 |
| M3 | 第 1 章通关率 30%~60%（内部 20 局统计）；Boss 战无机制误解；视觉 checklist 全过 |
| M4 | 新手引导 3 分钟流失 < 30%；无 P0 缺陷；视觉 checklist 全过 |
