# 11 第二章出生机制设计（虫巢驱动 · 无波次 · 以「虫核」为经济）

> 状态：设计稿（未实现）｜ 依赖：docs/09（侵蚀网/节点）、docs/10（对称对抗/无时间限制）
> 决策记录：① **虫巢可移动**；② 资源统一称 **虫核**；③ **不设"零战果腐朽"**（靠别的方式保证收敛）。
> 本文专门回答：**没有波次、没有时间限制之后，虫子到底怎么出生？**

---

## 0. 一句话

**虫子不再"按波次从上下左右刷"，而是"从虫巢身上、沿侵蚀网、在它当前所在的位置孵化出来"。**
出生 = **虫巢的花钱行为**：虫巢用「虫核」决定"在哪孵、孵什么、孵多少"。你打掉它的经济/节点，它就孵不出兵。

---

## 1. 三个出生来源（取代旧"波次刷怪"）

| 来源 | 机制 | 类比 |
|------|------|------|
| **① 虫巢孵化（主来源）** | 虫巢本体周期性"产卵"→ 在**虫巢当前所在位置附近**孵出单位 | 主基地造兵 |
| **② 节点孵化（分矿出兵）** | 每个侵蚀节点 = 一个"孵化点"，可独立孵兵（花虫核）；离城墙越近的节点孵出的兵**出生越靠前** | 分矿出兵 |
| **③ 事件孵化（爆发）** | 毁灭性事件：如"虫巢迁徙"落地、虫后产卵囊爆开、玩家逼近主核时"背水一战" | 召唤/大招 |

**核心原则：出生点 = 离它要攻击的目标最近的"己方孵化源"**。这就是"出生线前移"的真正来源——不是系统硬推，而是**虫巢把节点往前铺，前面节点就能孵兵**。

---

## 2. 出生规则（详细）

### 2.1 谁来决定出生？

虫巢 AI 每 **T 秒（初始 1.5s）**做一次"孵化决策"：

```
1. 结算虫核收入（当前存活节点数 × 每节点产出 + 虫巢本体产出）
2. 若是"进攻倾向"：优先在【最靠前、且未被地堡压制的节点】孵化
3. 若是"扩张倾向"：把虫核花在【长出新节点】上（见 docs/09）
4. 若是"防守倾向"（玩家逼近主核）：在【主核附近】孵化护卫
5. 虫核不足 → 什么都不做（经济被压制 → 断兵）
```

> **这就是"可以削弱对手发育"的落点**：玩家打节点/清虫 → 虫核收入下降 → 虫巢孵不出兵 → 玩家争取到窗口。

### 2.2 出生位置的选择（关键：可读、可反制）

- **优先**：最靠前的可用孵化点（节点/主核）。
- **约束**：孵化点必须**存活、未被地堡覆盖**、且**离城墙有一定最小距离**（不能贴脸到看不见）。
- **出生表现**：孵化点先"鼓包 / 冒泡"（0.8s 预警）→ 喷发孢子 → 虫子钻出（与 docs/09 的"出土喷发"一致）。
- **玩家反制**：烧断节点 → 该点停止孵化；地堡压制 → 该点无法孵化；清空节点旁 → 让出生点"无功可出"。

### 2.3 出生节奏（无波次之后靠什么形成"节奏感"）

没有 `durationSec`，节奏由**经济曲线**自然形成：

| 阶段 | 虫核收入 | 表现 |
|------|----------|------|
| 初生 | 低（只有主巢 + 1~2 节点） | 稀稀拉拉孵几个，压力小 |
| 发育 | 中（节点增多） | 出生频率变高，开始成批 |
| 高潮 | 高（节点铺到前沿） | 连续孵化，贴脸压制 |

**关键**：节奏不是"时间到了就刷一波"，而是**"你让它的经济涨到多少"**——这是从塔防转向对抗的核心。

## 3. 虫巢可移动（你的决策 ①）

### 3.1 移动规则

| 项 | 设定 |
|---|---|
| **默认** | 虫巢**驻留**在场地深处（y≈1750~1850），不随意移动 |
| **移动触发** | ① 主核护甲被削到某档（感到威胁）→ 后退；② 玩家逼近到一定距离 → **迁移**；③ 定期"换巢"（如每 90s 小范围挪动，防止被定点爆破） |
| **移动方式** | **沿侵蚀网移动**（沿连线"爬行"到另一个节点位置），移动时有 1.5s"迁徙"状态：**期间不孵化、护甲临时 +X%**（给你"趁迁徙打"或"趁迁徙被压制"的博弈） |
| **移动上限** | 单次移动距离有限（如 ≤ 2 个节点），不能瞬移到玩家脸上 |
| **出生影响** | 虫巢移动到哪里，**主巢孵化点**就跟着走 → 主巢孵出的兵出现在新位置 → 出生线随巢而动 |

### 3.2 为什么"可移动"是好的

- 玩家**不能"锁定一个坐标怼输出"**，必须跟着它打 → 走位/推进更动态。
- 虫巢"逃跑"制造追赶感，但也让它**离开前沿**（暂时降低出生压力）——取舍。
- 与"侵蚀网"绑定：**想逼迫虫巢，就得先切断它的移动路线（烧连线）**。

### 3.3 可读性（必须）

- 虫巢移动时：**地面裂开 + 根须蠕动 + 拖出新的连线**（不是瞬移）。
- HUD 上有"虫巢位置"指示（顶部地图条），玩家知道它现在在哪。

## 4. 出生单位与解锁（无波次后靠"科技/经济"解锁，替代"第几波解锁"）

| 单位 | 解锁条件（替代旧波次） | 说明 |
|------|------------------------|------|
| 幼虫群 | 默认 | 基础炮灰 |
| 爬虫 | 虫巢累计孵化 ≥ N 或 虫核收入达 X | 肉盾/钻地回血 |
| 潜伏者 | 虫巢升级 1 次 | 伏击 |
| 虫后 | 虫巢升级 2 次 | 铺毯/治疗/产卵 |
| 毒爆虫 | 虫巢升级 2 次 | 拆设施主力（对地堡） |
| 雷兽 | 完成过 1 次"迁徙" 或 虫巢升级 3 次 | 大单位 |

> **由"发育进度"解锁，而不是"第几波"**——与"双方竞速发育"一致。玩家猛攻会打断它的解锁。

---

## 5. 与玩家侧的对称（玩家也"出生/生产"）

为防止变成"单方面挨打"，玩家也有对称的"生产":
- 玩家的"兵" = **英雄 + 武器（卡牌成长）**，不出小兵（保持单人操作爽感）。
- 玩家的"设施" = **塔/地堡/采集点**（docs/10），这些是虫族要拆的目标。
- **出生不对称**（玩家靠成长，虫族靠孵兵），但**发育竞速对称**（都在抢虫核/资源变强）。

---

## 6. 收敛机制（替代你取消的"零战果腐朽"）

因为你决定**不设"零战果腐朽"**，必须有别的收敛方式，否则无时间限制会拖：

1. **虫核总量有限**：节点数量有上限、且节点产虫核是"存量"不是"无限流量"→ 经济战有终点。
2. **发育封顶**：双方科技/卡牌最终到顶 → 比的是存量与操作。
3. **节点/资源先占先得**：不会凭空再生，抢完即确定。
4. **可认输**：劣势时玩家可结束，不强制拖。

> 若后期实测出现"长时间僵持"，可再议加回软性机制（如"资源越用越贵"的边际递减）。**当前按你的决定：不设腐朽。**

## 7. 工程映射（供开发）

| 设计 | 现状 | 需新增/改 |
|------|------|-----------|
| 出生来源 | `buildSchedule` 按波次时间轴 | 删除波次表；新增 `HiveSpawner`：按虫核余额 + AI 意图选孵化点 |
| 孵化点 | `fromCreep` 从虫苔随机 | `spawnSources = 节点[] + 主巢`；出生优先"最靠前可用源" |
| 虫核 | 无 | `hive.biomass`（虫核）；节点产出、孵兵花费 |
| 虫巢移动 | 无（只有 spawnBandY） | `hive.x/y` + 迁徙状态机（沿连线爬行，迁徙期不孵化+护甲加成） |
| 单位解锁 | 波次表决定 | 改为"虫巢升级等级/累计孵化数"门控 |
| 出生预警 | 无 | 孵化点鼓包 0.8s → 喷发 → 出土 |
| 精英/浪潮 | 波次 | 由 AI"进攻倾向"驱动（虫核富余时集中孵化） |

## 8. M1（先跑通"虫巢驱动的出生"）

1. 虫巢固定在顶部，**用虫核孵兵**（基础幼虫群），不再有波次。
2. 3~4 个侵蚀节点作为"孵化点"，靠前节点孵出的兵更靠前。
3. 玩家击杀掉虫核 → 虫巢孵化变慢/停止（验证"削发育"）。
4. 虫巢**一次小范围迁徙**（演示可移动）。
5. 单位仅解锁到"爬虫"（验证经济解锁，不用一次做全）。
6. 无时间限制、无腐朽。

> 先验证"**虫核经济 → 孵化 → 出生线 → 压制**"这条链路成立，再补虫后/毒爆/雷兽与完整 AI。
