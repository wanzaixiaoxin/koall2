# 01 战斗与数值系统设计

> 目标：定义"伤害怎么算"，保证后期数值可控、可读、可平衡。
> 所有数值先给**基准值**，实际以配置表调优。

---

## 1. 属性定义

### 1.1 角色（英雄/辅助/怪物共用一套属性模型）

| 属性 | 缩写 | 说明 | 基准 |
|------|------|------|------|
| 生命值 | HP | | 英雄 100，怪物见 04 文档 |
| 生命回复 | Regen | 每秒回血 | 0 |
| 攻击力 | ATK | 所有伤害计算的基数 | 10 |
| 攻击速度 | ASPD | 攻击间隔 = 基础间隔 ÷ ASPD | 1.0 |
| 移动速度 | MS | 像素/秒 | 英雄 160 |
| 护甲 | DEF | 参与减伤公式 | 0 |
| 暴击率 | Crit% | 0~100 | 5% |
| 暴击伤害 | CritDMG | 默认 150% | 150% |
| 冷却缩减 | CDR | 0~60%（硬上限） | 0 |
| 拾取范围 | Pickup | 经验宝石吸附半径 | 60px |
| 伤害加成 | DMG% | 独立乘区 | 0 |
| 弹道速度 | ProjSPD | 投射物飞行速度加成 | 0 |

### 1.2 伤害类型（5 种）

| 类型 | 颜色标识 | 特色状态 | 代表武器 |
|------|----------|----------|----------|
| 物理 | 白色 | 击退 | 子弹、回旋镖、箭矢 |
| 火焰 | 红/橙 | 燃烧（DoT，可叠加 3 层） | 炸弹、火球 |
| 冰霜 | 蓝 | 冰冻/减速（叠 5 层冻结 1s） | 冰箭、冰环 |
| 闪电 | 紫 | 感电（连锁跳跃 2~4 个目标） | 闪电链、雷球 |
| 毒 | 绿 | 中毒（DoT，可无限叠加，伤害递减） | 毒镖、毒雾 |

设计原则：**物理主打单体/击退控场，元素主打 AOE/状态连锁**。怪物对不同伤害类型有抗性/弱点（见 04 文档），逼迫玩家混编或针对性构筑。

## 2. 核心伤害公式

### 2.1 单次伤害

```
伤害 = ATK × 技能倍率 × (1 + DMG%) × 暴击系数 × 类型克制系数 × 浮动系数

暴击系数 = 暴击 ? CritDMG : 1
浮动系数 = 0.95 ~ 1.05（伪随机）
类型克制系数 = 克制 1.25 / 被抗 0.75 / 无关系 1.0
```

### 2.2 减伤（对怪物和玩家通用）

```
减伤率 = DEF / (DEF + 100 + 10×怪物等级)
实际伤害 = 伤害 × (1 - 减伤率)
```

- 选用"护甲/(护甲+K)"型而非百分比叠加，保证无限成长下有收益递减。
- 玩家侧 DEF 很低，主要靠走位；Boss 侧 DEF 较高，逼迫玩家堆穿透。

### 2.3 穿透

```
有效DEF = max(0, DEF × (1 - 穿透%) - 固定穿透)
```

### 2.4 状态效果（DoT 与控场）

| 状态 | 效果 | 叠加规则 | 刷新规则 |
|------|------|----------|----------|
| 燃烧 | 每秒 30% ATK，持续 3s | 最多 3 层，每层独立计时 | 刷新最旧层 |
| 中毒 | 每秒 20% ATK，持续 5s | 无限层，第 n 层伤害 ×(0.85^n) | 新层独立计时（上限 20 层） |
| 冰冻 | 移速 -20%×层数，5 层冻结 1s | 5 层触发冻结后清零 | 层数刷新 |
| 感电 | 受击时向 2~4 个附近敌人跳跃 25% 伤害 | 最多 1 层，持续 4s | 刷新时间 |
| 击退 | 位移 + 短暂硬直（Boss 有抗性递减） | 无叠加 | — |

**Boss 控制抗性**：同一控场效果 3 秒内重复触发，持续时间 ×0.5、×0.25……直至免疫 5 秒（防止无限冻结永动）。

## 3. 战斗节奏基准（用来反推所有数值）

| 时间点 | 玩家强度预期 | 同屏怪物 | 单发伤害预期 |
|--------|--------------|----------|--------------|
| 开局 0 分钟 | 1 把 1 级武器 | 5~10 | 10~15 |
| 5 分钟 | 2~3 把 3~4 级武器 | 40~80 | 30~60 |
| 10 分钟（Boss） | 3~4 把 5~8 级 + 1 把超武 | 80~150 + Boss | 80~200 |

**经验曲线**（升到下一级所需经验，按"每波 1~2 次三选一"反推）：
```
ExpNeed(Lv) = 8 + 4×Lv + 0.6×Lv²
```
第 1 关单局期望等级 Lv15~17（≈16 次三选一）。

## 4. 伤害结算管线（开发实现要点）

```
投射物命中 →
  1. 命中检测（碰撞/距离判定，含"已命中列表"防多段重复）
  2. 伤害计算（读 attacker 属性 + 上表公式）
  3. 伤害类型分发：直接伤害 + 附加状态（StateComponent）
  4. 目标受击：扣血 → 飘字 → 击退/硬直 → 死亡判定
  5. 事件广播：onHit / onKill / onCrit（供吸血、连锁、卡牌效果监听）
```

关键约束：
- 所有伤害计算**纯函数化**（输入属性快照，输出结果），方便单元测试与数值模拟。
- 伤害飘字走对象池 + 上限截断（同屏最多 40 个）。
- 击杀事件驱动掉落与统计，不做轮询。

## 5. 平衡工具（开发侧必须做）

1. **数值模拟脚本**：给定玩家构筑 + 怪物血量曲线，模拟 10 分钟 DPS 曲线，输出 TTK（击杀时间）报表 —— 用于验证"是否能清动怪潮"。
2. **游戏内调试面板**：实时显示 DPS、击杀数、当前帧怪物数、投射物数。
3. **所有数值走配置表**（JSON / Cocos 的 assets 配置），热更可调，禁止硬编码。

## 6. 城墙（基地）系统与胜负判定

### 6.1 规则
- 城墙是关卡实体：最下方一排城垛，MVP **整排共享一条城防血条**（不做分段；分路段维修为第二里程碑扩展）。
- 城防血量按关卡配置（第 1 关基准 800，随关卡 +25%/关）；城墙无减伤、无回复（除修城锤/修城卡），受到的是怪物"对墙伤害"（见 04 文档 §1）。
- 反馈设计：受击抖动 + 城垛按血量百分比破损（100%/70%/40%/20% 四档表现）；血量 <30% 时屏幕边缘红光告警 + 低频心跳音，制造"城要破了"的紧迫感。

### 6.2 胜负判定
- **失败**：城防血条 ≤ 0 → 城破演出（城墙坍塌动画 + 慢动作）→ 失败结算（保留 50% 金币与全部材料）。
- **胜利**：消灭本关所有波次的怪物（含收尾精英/Boss 波）→ 按剩余城防血量评星（>70% 3 星 / 40~70% 2 星 / <40% 1 星）→ 胜利结算。

### 6.3 英雄生存（MVP 约定）
- MVP 英雄**不受伤、无 HP**（怪物只攻击城墙）。走位的风险与收益来自：补漏（拦 fast_rush/精英）vs 抢经验宝石（宝石掉在战场区怪物死亡点）vs 站位（辅助光环/武器射界）。
- 第二里程碑困难模式：远程怪弹丸可击中英雄，英雄 HP 与城防血条任一归零即失败。

### 6.4 数值校验（新增硬性校验项）
- 对墙 DPS 预算表：每种怪对墙 DPS × 每波数量 = 该波磨墙压力；任一时刻场上"潜在对墙总 DPS"≤ 城墙 DPS 承受上限的 60%。
- TTK 校验：每波总 HP ÷ 玩家期望 DPS ≤ 60s（波次不超过 1 分钟清完，保证节奏）。
- 以上两条由数值模拟脚本在每份波次表提交时自动校验。
