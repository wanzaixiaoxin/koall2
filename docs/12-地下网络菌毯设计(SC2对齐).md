# 12 地下网络（菌毯）设计 —— 对齐《星际争霸2》Creep 系统

> 状态：设计稿（未实现）｜ 修订 docs/09「侵蚀网」、docs/11「出生机制」中的地下网络部分
> 决策：地下网络**按 SC2 的菌毯（Creep）系统设计**；虫巢可移动；资源=虫核；无时间限制、无腐朽。

---

## 1. 为什么参考 SC2 菌毯（它好在哪里）

SC2 菌毯是一套**成熟、可读、有攻防张力**的"地下扩张"系统，恰好满足你的三点诉求：
1. **不断侵蚀、蔓延** → 菌毯从主巢向外长。
2. **让出生越来越靠近城墙** → 菌毯瘤可以往前铺，虫族只能在菌毯上出兵/建建筑。
3. **可削弱对手** → 菌毯瘤是**可被击杀的具体目标**，杀瘤 = 断它扩张。

并且 SC2 菌毯天然有"**扩张 vs 防守**"的博弈和"**切瘤**"的操作乐趣，比抽象"节点网"更好实现、更好读。

## 2. SC2 菌毯的六条核心规则（照搬）

| # | SC2 规则 | 本作映射 |
|---|----------|----------|
| 1 | **主巢自带一圈菌毯**（Hatchery 周围固定半径） | 虫巢（Hive）周围 1 圈菌毯；虫巢可移动则这圈跟着走 |
| 2 | **菌毯瘤（Creep Tumor）** 是有 HP、会前进的独立单位，由虫后/特定单位放置 | 「菌毯瘤」= **地下网络的建设单位**，可被击杀 |
| 3 | **瘤朝"远离其他菌毯源"的方向增殖**（避免重叠），每 ~8s 前进 1 格 | 瘤按"离其他瘤/主巢最远方向"扩散，节奏可调 |
| 4 | **虫族只能在菌毯上建造/出兵** | 虫族**孵化点必须在菌毯上**（出生线前移的来源） |
| 5 | **菌毯本身不可攻击，但菌毯瘤可击杀；杀瘤→该瘤辐射的菌毯回缩** | 菌毯地面只作视觉/标记；**打瘤 = 切走一片菌毯** |
| 6 | **菌毯瘤数量受产能限制**（主巢/虫后产出） | 瘤数量受"虫巢等级 + 虫核"限制 → 经济制衡 |

> 关键修正（相对 docs/09 的"抽象节点网"）：
> - **"节点"改名为"菌毯瘤"，且必须是可被击杀的具体单位**（不是"打不到的抽象节点"）。
> - 菌毯**只提供移动加速 + 作为建造/出生的地面**，**不再给"血条/攻击加成"**（这是 SC2 的原规则；之前 docs/09 的"供血供能加攻血"取消，改为经济/出生层面）。

## 3. 本作的菌毯系统（完整设定）

### 3.1 三层结构（视觉 + 逻辑分离）

| 层 | 是什么 | 可否攻击 | 作用 |
|----|--------|----------|------|
| **菌毯地面（Creep）** | 铺在地上的酸绿地膜（90px 网格） | ❌ 不可攻击 | 判定"是否在菌毯上"；虫族移动 ×1.25；视觉 |
| **菌毯瘤（Tumor）** | 立在地面、有 HP 的小型虫巢组织 | ✅ **可击杀** | 扩张菌毯的"发动机"；击杀 → 其辐射范围内的菌毯**回缩** |
| **虫巢（Hive）** | 移动的主核 | ✅（有茧壳护甲） | 自带一圈菌毯；产虫核；孵兵 |

### 3.2 菌毯的扩张逻辑（照 SC2）

```
每个菌毯瘤每 8 秒执行一次增殖：
  1. 找一个"离所有其他菌毯源(主巢/其他瘤)最远、且在自身辐射范围内"的方向
  2. 若该方向未到最大扩散半径 → 向该方向把菌毯扩 1 格（90px）
  3. 可随机在"扩张前沿"生出一个新菌毯瘤（受数量上限约束）
```

- **最大扩散半径**：每个瘤最多把菌毯推到 1.5 格远处（有限，不是无限铺）。
- **朝城墙方向优先**：当多个方向等价时，**优先朝城墙（-y）** → 这就是"不断向城墙蔓延"。
- **瘤数量上限** = 虫巢等级 × 2 + 基础值（对应虫核产能），防止无限铺。

### 3.3 菌毯的清除（攻防核心）

| 手段 | 效果 |
|------|------|
| **击杀菌毯瘤** | 该瘤辐射的整片菌毯**回缩**（连带前沿出生点失效） |
| **火焰烧地面** | 烧掉一段菌毯地面（不留瘤），但**不杀瘤** → 只能切"地面"，不能断"发动机" |
| **地堡压制** | 地堡覆盖区**永久免疫菌毯**（菌毯无法长入，已长的被顶掉）→ 玩家的"抢地"手段 |

> **张力**：想真正压制虫族，必须**打掉菌毯瘤**；但瘤有 HP、有虫群保护 → 需要火力/走位突破。火焰只能"临时清地"，地堡只能"守地"，**打瘤才是进攻**。

### 3.4 菌毯与出生（衔接 docs/11）

**虫族只能在菌毯上孵化单位**（SC2 规则 4 的直接结果）：
- 出生点 = **最靠前的、未被地堡压制的菌毯瘤**位置。
- 因此"出生线前移" = **菌毯瘤往前铺到哪，兵就从哪出**。
- **打掉前沿瘤 → 出生线立刻回退**（玩家最直接的"削弱发育/压制"手段，可读、可操作）。

### 3.5 菌毯与虫核（经济）

- **菌毯覆盖面积**是虫核产出的一部分（面积越大，虫核收入越高）。
- 菌毯瘤本身**不直接产虫核**（成本项），但它的扩散带来更多可利用面积 → 间接收益。
- **虫核产能** = 主巢基础 + 菌毯覆盖格数 × 系数 → **压制菌毯 = 直接砍它经济**。

## 4. 与 SC2 的差异（本作必要的改编）

| SC2 | 本作 | 原因 |
|-----|------|------|
| 菌毯只加速，不加强 | 本作同样**只加速**（取消之前"加攻血"） | 对齐 SC2 + 避免数值失控 |
| 菌毯瘤由虫后手动放置 | 本作**AI 自动放置**（玩家不打虫族，虫族是对手） | 无 RTS 微操，需自动化 |
| 虫族建筑需在菌毯上 | 本作"孵化点需在菌毯上" | 保留"出生线"逻辑的核心 |
| 菌毯值/能量消耗 | 改为虫核花费 | 统一经济 |

## 5. 视觉设计（对齐 docs/06 色板，酸绿族）

| 元素 | 构成 | 动效 |
|------|------|------|
| 菌毯地面 | 半透明暗绿地膜 + 有机脉纹 + 边缘亮弧（沿用现有 creep 离屏缓存绘制） | 蔓延时边缘有"推进波" |
| **菌毯瘤** | **小型虫巢组织：深绿肉瘤 + 顶部一圈亮黄绿脉动孢子囊 + 数根根须扎地**，直径约 40px | 每 8s 增殖时"鼓胀→喷射孢子"；受击闪白（沿用 fx-config hitFlash） |
| 回缩效果 | 瘤被击杀 → 它辐射的菌毯从边缘向中心**焦枯回卷**，孢子飘散 | 消退动画 0.6s |
| 虫巢（Hive） | 大型多层虫核（比瘤大数倍），可移动时拖出根须 | 迁徙时地面裂开 |

> 可读性：**瘤必须一眼可辨、可瞄准**（它是攻击目标）；菌毯地面弱化（半透明，不抢弹幕亮度）。

## 6. 工程映射

| 设计 | 现状（`session.ts`） | 改动 |
|------|----------------------|------|
| 菌毯地面 | `creep: Map<key, until>`（90px 网格，有存活时间） | 改为**无时限**（随瘤存在），增加 `owner`/辐射源标记 |
| 菌毯瘤 | **无** | 新增 `tumors: {x,y,hp,r,nextSpread,rSourceId}[]`；可被武器索敌/击杀（进索敌表） |
| 增殖逻辑 | 无 | 每 8s：算"远离其他源"方向 → 扩 1 格 + 概率生新瘤（数量上限） |
| 出生点 | `fromCreep` 从虫苔随机 | 改为"最靠前菌毯瘤"，出生必须在菌毯上 |
| 火焰清地 | `burnCreep(x,y,r)` 已有 | 保留（清地面、不杀瘤） |
| 地堡压制 | 无 | 侵蚀/增殖时检测地堡覆盖 → 跳过；已覆盖被顶掉 |
| 虫核经济 | 无 | `hive.biomass`；菌毯格数 × 系数 计收入 |

## 7. M1（先跑通 SC2 式菌毯）

1. 虫巢（顶部固定）自带一圈菌毯。
2. 虫巢自动"放菌毯瘤"（每 8s 一个，受上限约束），瘤朝城墙方向蔓延菌毯。
3. **瘤可被武器击杀**；杀瘤 → 其菌毯回缩一块。
4. 虫族**只在菌毯上孵兵**（幼虫群+爬虫），出生点取最靠前瘤。
5. 地堡（先做静态占位）能"钉地"，瘤绕开它。
6. 火焰能烧地面（现有能力复用）。

> 验证"**铺毯→出生线前移→打瘤→出生线回退**"这条 SC2 式闭环。做完再接虫巢迁徙、虫核经济、更多单位。
