# 02 武器、投射物与索敌追踪设计

> 目标：定义武器库、投射物行为、飞行轨迹、追踪与索敌规则。
> 武器 = 发射器（何时发、索敌谁）+ 投射物（怎么飞、命中怎样）+ 命中效果（伤害/状态/AOE）。

---

## 1. 武器系统总结构

- 玩家最多携带 **4 把武器**（主英雄 1 把初始武器 + 升级卡获得）+ **4 个被动/辅助位**。
- 每把武器有 **8 个等级**：Lv1 获得 → Lv2~7 升级（数值/机制增强）→ Lv8 **超武进化**（需绑定辅助在场 + 对应被动）。
- 武器分两类：
  - **常驻自动武器**：按攻击间隔自动索敌发射（玩家只走位）。——主力
  - **主动技能型武器**：有冷却充能，玩家点击释放（可选设计，MVP 先全做自动型，操作量留给走位）。

### 武器数据模板（配置表字段）

```jsonc
{
  "id": "gun_rifle",
  "name": "符文步枪",
  "type": "projectile",          // projectile | melee | aura | summon | beam
  "damageType": "physical",
  "baseDamage": 12,
  "damageMulPerLv": 1.15,        // 每级攻击倍率
  "interval": 0.9,               // 攻击间隔(秒)
  "count": 1,                    // 每次发射数量
  "projectileId": "proj_bullet",
  "targeting": "nearest",        // 见 §5
  "evolveTo": "gun_rifle_ex",    // 超武 id
  "evolveRequire": { "assist": "assist_gunner", "passive": "passive_reload" }
}
```

## 2. 投射物类型库（MVP 4 种 + 扩展）

### 2.1 子弹（直线型）— MVP
- 轨迹：直线，命中第一个敌人消失（可穿透词条）。
- 参数：速度 600px/s，射程 500px，无重力。
- 定位：稳定单体 DPS 基准，所有武器以其为参照平衡。

### 2.2 箭矢（穿透直线型）— MVP
- 轨迹：直线高速（900px/s），**穿透 N 个敌人**（等级成长：1→3→5），每穿透一个伤害 -15%；破甲每级削减 5% 穿透衰减率（3 级归零，衰减系数封顶 1，永不超过原弹伤——docs 破甲设计）。
- 变体：抛物线箭（抛射越墙，打后排）。

### 2.3 炸弹（抛物线 AOE 型）— MVP
- 轨迹：抛物线（模拟重力），落点 = 索敌目标位置快照（发射时锁定，不追踪）。
- 命中：落地即爆，半径 80~140px AOE；附带击退 + 对怪物 1s 灼烧地面（火系）。
- 手感关键：落点预警圈（红色半透明圆）必须清晰。

### 2.4 回旋镖（往返型）— MVP
- 轨迹：飞出 300px 后原路返回（或做 8 字/椭圆环绕），往返各结算一次伤害，可穿透。
- 进化超武后变为环绕自身旋转的 2~3 个永久飞轮（参考 VS 的 King Bible）。

### 扩展（后续版本）
| 投射物 | 行为 | 定位 |
|--------|------|------|
| 闪电链 | 命中后自动跳向最近敌人（跳跃数成长） | 清密集怪群 |
| 激光/光束 | 即时命中直线扫射，持续 1~2s 可转动 | 定向割线 |
| 冰环/新星 | 以自身为中心扩散波 | 近战自保 |
| 追踪飞弹 | 强追踪 + 小 AOE | 点杀精英 |
| 毒雾瓶 | 落地生成持续 3s 毒雾区域 | 区域封锁/堵路 |
| 召唤物 | 独立 AI 单位（辅助单位的载体） | 编队感核心 |

## 3. 飞行轨迹系统（Trajectory）

实现上把"运动"抽象成可组合的轨迹组件（Strategy 模式），供所有投射物复用：

| 轨迹组件 | 参数 | 适用 |
|----------|------|------|
| Straight | 速度、射程、是否穿透 | 子弹、箭矢 |
| Parabola | 初速、重力、落点 | 炸弹、毒雾瓶 |
| Boomerang | 飞出距离、返回类型（原路/椭圆/环绕） | 回旋镖 |
| Homing | 转向角速度、追踪时长、丢失目标行为 | 飞弹 |
| Chain | 跳跃次数、跳跃半径、伤害衰减 | 闪电链 |
| Orbit | 环绕半径、角速度 | 超武飞轮、护盾球 |

**追踪（Homing）三规则**（防止无限追踪导致全场乱飞）：
1. 转向角速度上限（如 360°/s），飞得快的投射物转不过弯 → 有躲避空间。
2. 追踪时长上限（如 2.5s）超时沿当前方向飞直至射程结束。
3. 目标死亡 → 若支持重索敌则切换最近目标（默认切换 1 次），否则直线飞完。

## 4. 索敌规则（Targeting）

武器配置 `targeting` 字段，统一由 TargetingSystem 提供目标：

| 规则 | 说明 | 典型武器 |
|------|------|----------|
| `nearest` | 范围内最近（默认 90% 武器） | 子弹 |
| `lowestHp` | 范围内血量最低 | 补刀型 |
| `strongest` | 范围内血量最高（优先精英/Boss） | 狙击枪 |
| `random` | 范围内随机 | 炸弹（防止永远砸最近） |
| `densest` | 怪物密度最高的方向（扇形扫描投票） | 霰弹、闪电链 |
| `forward` | 英雄面朝方向，不索敌 | 手动技能 |
| `self` | 自身为中心 | 新星、光环 |

索敌性能要求：怪物按**空间网格（Spatial Hash）**索引，单次索敌 O(1) 均摊；每帧索敌次数 ≤ 武器数（攻击瞬间才索敌，不逐帧索敌）。

## 6. 辅助单位（编队）与武器的关系

- 辅助单位 = 自带一把"简化武器"的 AI 跟随单位（环绕/跟随英雄走位，自动索敌）。
- 辅助不占武器位，但**是武器进化的钥匙**（例：炸弹超武需要"炼金术士"辅助在场）。
- 辅助可升级（升级卡中刷新其专属强化），形成"主英雄武器 + 辅助武器 + 辅助增益"三层构筑。
- 羁绊（第二里程碑）：3 同系辅助触发流派效果（如 3 火系 = 全队火焰伤害 +25% & 燃烧可暴击）。

## 6. 武器谱系（分类与独有卡体系，docs/03 §2.2 目标门控）

每把武器 = **身份（role）+ 本体机制 + 4 张独有升级卡**；公共卡（强装药/形态/元素/属性/城墙）全武器共享。

| 武器 | 谱系 | 本体机制 | 独有卡（特性卡加粗） |
|------|------|----------|------------------------|
| 符文步枪 | 速射系 · 弹幕雨 | 高射速(0.55s)低单发(9)，直线弹 | 齐射 / 连射 / 急速弹 / 长枪管 |
| 穿透弩 | 贯穿系 · 重狙穿线 | 低速重箭(24/1.6s)，穿透 3（衰减 18%/次，破甲每级 -6%） | 贯穿 / 重弩装药 / 多重箭 / 远瞄 / **跳箭（弹射）** |
| 炼金炸弹 | 爆破系 · 抛物轰击 | 抛物线弹道 + 落地爆破圈（blastBase） | 双掷 / 大装药 / 远投 / 速燃 / **弹片（分裂）** / **扩爆（爆破成长）** |
| 回旋镖 | 回旋系 · 血滴子 | 飞出→**悬停研磨 2s（0.5s 重击冷却反复切割）**→返回（phased motion） | 锋刃 / 轻身 / 双盘 / 长旋 / **导向镖（追踪）** |
| 雷电权杖 | 雷霆系 · 连锁落雷 | 无弹体，落雷连锁跳跃（chainBase） | 连锁长度 / 闪击 / 电弧延伸 / 双雷 |

**形态即武器特性原则**：改变武器行为形态的词缀（追踪/弹射/分裂/爆破）一律做成武器专属卡，挂靠最贴合其身份的武器；公共池只保留数值向（强装药/属性）、弹药向（破甲弹）、元素向（赋予/加持）与城墙卡。

**设计约束（校验+测试保证）**：
1. 每把武器 ≥3 张专属卡（lab 断言 `W-谱系完整性`）；
2. 专属卡只作用于目标武器（`target.kind='weapon'` 门控），其他武器构筑中不可见；
3. 本体机制走 `WeaponConfig`（chainBase / blastBase / motion），不占词缀槽——"爆破落地"卡可在本体基础上继续叠爆炸；
4. 新武器接入清单：weapons.json 加配置（role/motion/本体机制）→ cards.json 加 4 张专属卡 → 完成（选择器/门控/实验室自动生效）。
