# 04 怪物、精英、Boss 与波次 / 关卡设计

> 目标：怪物是"弹幕的靶子 + 磨墙的压力源"。设计上要让怪潮形成**多路漏怪压力**（不同出生点、不同速度同时压向城墙），逼迫英雄在底部区域走位补漏，而不只是数值压力。

---

## 1. 怪物基础模型

```
Monster = 属性(HP/DEF/ATK/MS) + 碰撞体(半径) + AI行为 + 掉落表 + 族群标签
```

| 属性 | 说明 |
|------|------|
| 碰撞半径 | 9~28px，小怪小而密，精英/Boss 大 |
| AI 行为 | 行军目标统一为**城墙**（MVP 怪物不攻击英雄，见 §1.2 约定） |
| 族群标签 | 兽人/亡灵/虫群/机械…（对应章节主题与弱点表） |
| 经验值 | 击杀掉落经验宝石 = HP 的 1/20（基准） |
| 对墙伤害 | 近战怪 = ATK × 攻速；远程怪 = 弹丸对墙伤害 |

### 1.1 行为库（移动 + 攻击行为，差异化核心）

通用规则：怪物从屏幕上方出生带刷出，向下推进；近战怪抵达城墙后转为 `assault_wall` 驻留攻击，远程怪在射程内停下射击城墙。

| 模式 | 描述 | 用途 |
|------|------|------|
| march | 直线压向城墙 | 基础杂兵 |
| zigzag | 蛇形向下行军 | 躲直线弹道的烦人小怪 |
| dash | 周期性短冲刺（前摇 0.4s 预警线） | 快速冲墙的尖峰压力 |
| fast_rush | 高移速低 HP，无视战场直奔城墙 | 逼玩家优先拦截补漏 |
| ranged | 距城墙 250px 处停下，弹丸攻击城墙（弹丸可被英雄身体挡下？否——MVP 打墙，玩家只能尽快击杀） | 持续磨墙压力 |
| splitter | 死亡分裂 2~3 个小怪 | 数量爆炸 |
| shielded | 正面护盾（需穿透/炸弹/超武处理） | 克制单一弹幕 |
| assault_wall | 抵达城墙后驻留攻击城墙（对墙 DPS = ATK × 攻速，有挥击动作与城垛受击反馈） | 所有近战怪的终点行为 |
| boss_pattern | 阶段化技能循环（见 §4 Boss 节） | Boss |

怪物间必须有**物理分离（flocking separation）**，防止叠成一团堵死单路；同屏 200 只时分离计算用空间网格 + 只算近邻。

### 1.2 英雄生存约定（重要）
- **MVP：英雄不受伤、无 HP**，怪物只攻击城墙。走位风险来自"漏怪磨墙"和"抢经验宝石"的取舍。
- 第二里程碑（困难模式 / 特定章节）：引入远程怪弹丸可击中英雄、英雄 HP，**英雄 HP 与城防血条任一归零即失败**。

## 3. 精英怪物

- 在普通怪基础上强化：**HP ×12、体型 ×1.6、掉落宝箱**（开出武器升级/稀有卡）。
- 对墙威胁是普通怪的 10 倍以上（要么大额单次重击，要么高攻速磨墙），是"必须立刻处理"级的压力。
- 随机附加 1~2 个词缀：
  - `狂暴`：半血后攻速/移速 +40%
  - `坚硬`：护甲 +50%
  - `迅捷`：移速 +60%
  - `破坏`：对墙伤害 +50%（守城玩法专属高危词缀）
  - `分裂`：死亡分裂 2 个本体弱化版
- 出场方式：该波开始前横幅预警"精英来袭" + 专属出场点（不混在杂兵堆里），头顶常显血条与词缀图标。

## 4. Boss 设计（第 1 章 Boss：腐化树人）

**设计原则：Boss = 本章机制的总验收**——检验玩家能否在处理多路小怪的同时对 Boss 输出、并及时清掉 Boss 召唤的磨墙物。

| 阶段 | HP 阈值 | 行为循环 |
|------|---------|----------|
| P1 100%~70% | 缓慢压向城墙，近战后重击城墙（单次大额城伤，明显预警）+ 召唤 4 史莱姆 |
| P2 70%~30% | 新增：远程投掷（随机 5 个红圈 1s 后落石，砸墙并封英雄走位）+ 移速 +20% |
| P3 <30% | 狂暴：技能间隔 -30%，新增全屏震荡波（留缺口，考走位与拦截时机） |

- Boss 血量以"玩家 DPS 达标时战斗 60~90 秒"为目标反推。
- Boss 战期间仍以小预算刷杂兵（保持割草感与经验来源），但密度减半。
- Boss 死亡 → 慢动作 + 城墙幸存演出 + 大宝箱 + 额外三选一（稀有以上）。

## 5. 波次导演（Wave Director）——固定波次制

关卡胜负依赖"波次清空"，因此刷怪采用**固定波次表 + 波内随机**（可控、可验收）：

```
每关配置 N 个波次（第 1 关基准 10 波；普通关 8~15 波）
  波次 i = { 怪物构成表、出生阵型（stream/line/pincer/center）、出怪总时长 durationSec（约 60s） }
导演按波次推进状态机：
  prepare(预警横幅) → spawning(durationSec 内连续多段放怪) → clearing(场上怪 = 0)
  → intermission(数秒休整) → 下一波 … → final wave → 全部清空 = 胜利
出怪模型（段潮制，避免"出完→清空→停顿"的断裂感）：
  一波总怪数切成 3~7 段潮（按总数/12），段内 3~5 秒密集进场（一小股怪潮），
  段与段时间重叠衔接——前段尚未清完，后段已在路上，场上始终保持压力；
  每段沿用波次阵型决定出生点，进场顺序保留随机性。
刷怪位置：屏幕上方出生带设 5~7 个出生点，波次配置指定"单路 / 双路 / 全路"
波内随机：同波次每局从 2~3 套"构成变体"抽一套 + 20% 数量扰动（M2）
```

- 波次节奏设计（第 1 关示例，sim 验证后实现值）：
  - 1~3 波：教学段潮（史莱姆 → 冲锋鼠/野狼），40~55 秒/波
  - 4~6 波：混入投矛手（远程磨墙）与岩甲兽（肉盾），55~65 秒/波
  - 7~9 波：多兵种混编密度潮，60~70 秒/波
  - 第 10 波：收尾大潮（100+ 只，80 秒），boss 关替换为 Boss 战
- **压力校验式**：任一波次怪物"潜在对墙总 DPS"换算的破墙时间过短（<30s）→ 警告复核；经验曲线按"每波 1~2 次三选一"反推（docs/01 §3）。
- 休整期：波间停火数秒给玩家喘息；经验为击杀自动吸收，无拾取负担；第二里程碑可加波间商店/事件卡。

## 6. 关卡模式

### 6.1 章节结构（产品节奏）

```
第 N 章 = 普通关 ×6~8 → 精英关 ×1 → Boss 关 ×1
```

| 关卡类型 | 波次 | 规则 | 目的 |
|----------|------|------|------|
| 普通关 | 10~15 波 | 固定波次全清即胜利，城破即败 | 刷经验/金币，构筑成型 |
| 精英关 | 12 波 | 3 个波次含精英，密度 +30% | 资源关（掉宝箱/材料） |
| Boss 关 | 8 波 + Boss 战 | 8 波小怪后进入 Boss 收尾波 | 章节验收 |

- 失败结算（城破）：保留 50% 金币与全部材料；关卡进度不保留，重开本关。
- 胜利结算：按剩余城防血量评星（>70% = 3 星，40~70% = 2 星，<40% = 1 星）；三星关联额外奖励/扫荡（第二里程碑）。
- 每章一个**环境机制**（第 2 章夜间视野收缩、第 3 章随机毒沼区…）防止换皮疲劳。

### 6.2 关卡内布局（单屏竞技场）

```
┌─────────────────────────┐
│      怪物出生带（上方）    │
│                         │
│      战场区（怪物行军）    │
│                         │
├─ 防守区域（英雄可移动）──┤  ← 英雄活动范围：底部约 25% 高度矩形区
│  🧝  🏹  🤖（辅助环绕）    │
╞═ 城墙（最下方一排城垛）═╡  ← 城墙线，怪物抵达后驻留攻击
└─────────────────────────┘
```

- 单屏不卷轴：设计分辨率 1080×1920，全战场信息一屏可见、零遮挡是硬要求。
- 英雄活动区域：底部矩形区（y 范围配置化，默认屏高 22%~47% 区间），触屏拖动/虚拟摇杆移动，出界钳制。
- 城墙：最下方一排城垛，视觉上分段破损、逻辑上一条城防血条；怪物从城墙上沿爬入攻击。
- 障碍物（第二里程碑）：战场区树木/岩石改变行军路线，增加绕路变数。

## 7. 掉落系统

> 经验**击杀自动吸收**（无拾取操作、无磁石机制），玩家的走位决策全部服务于"防漏与输出"。

| 掉落 | 触发 | 说明 |
|------|------|------|
| 经验 | 击杀即自动入账 | 数值 = 怪物配置 xp 字段；另有每波清空奖励（level 配置 `waveClearBonusXp`） |
| 金币 | 20% 概率（结算发放入库） | 局外货币 |
| 修城锤 | 稀有掉落 / 卡牌获得 | 恢复城防 15%（MVP 城墙唯一的回复手段） |
| 宝箱 | 精英/Boss | 直接开卡（相当于免费升级） |
